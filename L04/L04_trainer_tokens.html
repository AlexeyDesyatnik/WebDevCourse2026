ТЗ

Заказ буфета «Северный пирог». Оформи страницу так, чтобы палитру можно было поменять одной правкой.

Как сделать кодом

  1. Заведи в :root переменные: фон, фон карточки, текст, приглушённый текст, акцент, граница.
  2. Ниже — ни одного цвета значением, только var().
  3. Шрифт и цвет текста задай один раз на body.
  4. Карточка пирога: фон, рамка, скругление, отступ.
  5. Цена: жирная, акцентным цветом.
  6. Добавь тёмную тему через html[data-theme="dark"].

Как сделать блоками

Разметка уже готова. Собери CSS: токены, тёмная тема, body, карточка, цена. Лишние чипы — без двух дефисов, цвета значениями, !important.

Самопроверка

Проверки смотрят вычисленные стили в превью и способ записи в коде. Тёмную тему в превью не переключаем.

Подсказки

Три подсказки. На демо — своими словами.

Сколько раз в твоём файле встречается один и тот же цвет? Если больше одного — он просится в переменную. И второй вопрос: если сейчас поменять фон на тёмный, какие элементы останутся светлыми?
Порядок работы: сначала блок :root с шестью переменными — фон, фон карточки, текст, приглушённый, акцент, граница. Потом body с var(). Потом .card и .price с var(). В самом конце — второй блок html[data-theme="dark"] с теми же именами и тёмными значениями.
:root {
  --pie-bg:          #f4f6f3;
  --pie-card:        #ffffff;
  --pie-text:        #111312;
  --pie-muted:       #6b706b;
  --pie-accent-dark: #5fa22e;
  --pie-border:      #e3e7e1;
}
html[data-theme="dark"] {
  --pie-bg:          #0f0f0f;
  --pie-card:        #17191a;
  --pie-text:        #f2f4f1;
  --pie-muted:       #9ba29b;
  --pie-accent-dark: #7cc142;
  --pie-border:      #262a26;
}
body {
  background: var(--pie-bg);
  color: var(--pie-text);
}

Эталонное решение

Откроется, когда все проверки зелёные или открыты три подсказки.

Почему так: цвета живут в :root как --pie-*. Ниже только var() — иначе тёмная тема не переключит карточку. Второй набор в html[data-theme="dark"] обязан повторить те же имена. Без !important и без селекторов по id.


      

    


    

      
Глоссарий занятия

      

        
CSS-переменная

        
Своё имя для значения: --pie-accent. Объявляется один раз, используется везде.

        
:root

        
Селектор корня документа. Место, где объявляют переменные.

        
var()

        
Подставить значение переменной: color: var(--pie-accent).

        
Тёмная тема

        
Второй набор тех же переменных в html[data-theme="dark"]. Правила ниже не дублируют.

        
Селектор по классу

        
.card — основной инструмент оформления. id для стилей не берём.

        
!important

        
Глушит каскад. На курсе не используем: сначала разбираем, почему правило не применилось.

        
Наследование

        
Цвет и шрифт с body переходят детям. Фон и рамка — нет.

        
Контраст

        
Для основного текста не ниже 4.5:1. Светлый акцент на белом не читается — берём --pie-accent-dark.

      

    


    

      Карточка педагога
      
    
        
  • Навык: :root токены --pie-*, var(), тёмная тема теми же именами, оформление классами.
    • 
        
  • Норматив: 15–25 мин. Код или блоки. Scaffolding — образец.
    • 
        
  • Типичные ошибки: pie-bg без двух дефисов; цвет значением на body; потерянная переменная в тёмном наборе; !important; #card1.
    • 
        
  • Готово, когда: 10 зелёных и вслух: зачем имена в светлой и тёмной теме совпадают.
    • 
        
  • Усложнение: :hover и :focus-visible у карточки — не входит в тесты.
    • 
        
  • Поддержка: режим блоков; сначала :root, потом body, потом тёмная тема и сверка имён.
