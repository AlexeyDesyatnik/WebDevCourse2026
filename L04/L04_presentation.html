►► ЗАКАЗ

«Похоже на объявление, которое повесили на дверь»

Марина Петровна посмотрела работу и сказала именно так. Разметка верная — вида нет

►► ПОНЯТИЕ

Три части правила

  • Селектор — кому
  • Свойство — что меняем
  • Значение — на что

Пара «свойство: значение» — объявление. Точка с запятой после каждого

.card {
  background: #ffffff;
  padding: 16px;
}

►► ПОНЯТИЕ

Три селектора

  • p — по тегу, всем абзацам
  • .price — по классу, основной инструмент
  • #form — по id, одному элементу

Правило курса: оформление — классами. id — для JavaScript и label for

ul { list-style: none; }
.card { padding: 16px; }
#order { background: #edf7e4; }

CSS не выполняется сверху вниз. Он соревнуется

►► ПОНЯТИЕ

Каскад: кто побеждает

  • По специфичности: тег < класс < id < style в теге
  • При равной — побеждает написанное ниже
  • Соревнование идёт по каждому свойству отдельно
p        { color: black; }
.note    { color: gray; }
#warning { color: red; }

►► ЖИВОЙ КОД

Перечёркнутое правило — это ответ

В DevTools, панель Styles: правила идут от победителя к проигравшим. Проигравшие перечёркнуты

Последовательность на весь курс: не работает стиль → DevTools → выдели элемент → прочитай применённые и перечёркнутые

►► ТАК НЕЛЬЗЯ

!important вместо разбора

►► ТАК НЕЛЬЗЯ

Сработает. И после этого переопределить цвет нельзя ничем, кроме второго !important. Через месяц весь файл такой

Правило курса: !important не используется без объяснения педагогу

.price { color: #5fa22e !important; }
.card .price { color: #111312; }

►► ВОПРОС

Правила нет в DevTools или оно есть, но перечёркнуто — в чём разница?

Обсуждаем вслух. Это два разных диагноза с разным лечением

►► ПОНЯТИЕ

Наследование

  • Наследуются свойства текста: цвет, шрифт, размер, межстрочный
  • Не наследуются: отступы, рамки, фон, размеры
  • Значит, общее задают один раз на body

Исключение: поля формы и кнопки шрифт не наследуют

body { font-family: Arial, sans-serif; }
input, button { font-family: inherit; }

►► КРЮЧОК

«Слишком яркий, сделайте потемнее»

Твой зелёный встречается в файле пять раз: заголовок, цена, рамка хита, кнопка, ссылка. Найдёшь все пять? А если их двадцать?

►► ЖИВОЙ КОД

Переменные: значение с именем

  • Объявляем в :root — оттуда видно всей странице
  • Два дефиса в начале обязательны
  • Подставляем через var(--имя)
  • Имя по роли, а не по цвету
:root {
  --pie-accent: #7cc142;
}
h1 { color: var(--pie-accent); }

►► ЖИВОЙ КОД

Тёмная тема — это десять строк

Второй набор тех же переменных. Правила ниже не трогаем вообще: они обращаются по имени, а не по значению

html[data-theme="dark"] {
  --pie-bg:   #0f0f0f;
  --pie-text: #f2f4f1;
}

►► ТАК НЕЛЬЗЯ

Забыть переменную в тёмном наборе

►► ТАК НЕЛЬЗЯ

Ничего не сломается. Просто один элемент останется в старом цвете — обычно это тёмный текст на тёмном фоне

html[data-theme="dark"] {
  --pie-bg:   #0f0f0f;
  --pie-card: #17191a;
}

►► ПРАКТИКА

Что делаешь сегодня

  • Заводишь палитру буфета в :root
  • Оформляешь карточки, цены, форму
  • Добавляешь тёмную тему
  • Тренажёр: два режима

Сделано, если: ниже :root нет цветов значениями, в тёмном наборе те же имена, текст читается в обеих темах, !important нет

►► ИИ НА ЗАНЯТИИ

Промпт: палитра и тёмная тема

Ты подбираешь цветовую палитру для учебного веб-проекта.
Контекст: страница школьного буфета «Северный пирог» — северная домашняя выпечка, аудитория 13–18 лет. Стек: только HTML и CSS, без библиотек. Палитра будет задана CSS-переменными в :root.
Задача: предложи палитру из шести цветов — фон страницы, фон карточки, основной текст, приглушённый текст, акцент, граница. Плюс второй набор тех же шести для тёмной темы.
Ограничения: цвета в шестнадцатеричном формате; имена переменных с префиксом --pie- и по роли, а не по цвету; контраст основного текста к фону не ниже 4.5:1; акцентный цвет один и тот же в обеих темах или почти тот же; никаких градиентов и никаких библиотек.
Формат ответа: готовый блок CSS с двумя селекторами — :root и html[data-theme="dark"]. Ниже — таблица: переменная, светлое значение, тёмное значение, где применяется.
Критерии проверки: имена переменных совпадают в обоих наборах; ни одна переменная не потеряна во втором наборе; указан контраст текста к фону для каждой темы.

Проверить руками: имена совпадают в обоих наборах · все шесть на месте · текст читается · имена по роли · нет лишнего · можешь объяснить каждую

Правило курса: сдаётся только то, что ты можешь объяснить

Глоссарий занятия 4

CSS
Язык оформления. Задаёт, как выглядит то, что размечено в HTML.
Правило CSS
Селектор плюс набор объявлений в фигурных скобках.
Селектор
Указание, к каким элементам применить правило.
Свойство
Что меняем: color, font-size, background, padding.
Значение
На что меняем: #7cc142, 24px, 700.
Объявление
Пара «свойство: значение». Заканчивается точкой с запятой всегда, включая последнее.
Селектор по тегу
p { … }: применится ко всем абзацам страницы.
Селектор по классу
.card { … }: применится к элементам с class="card". Основной инструмент оформления.
Селектор по идентификатору
#form { … }: применится к одному элементу с id="form". Для оформления не используем.
Модификатор
Дополнительный класс, меняющий одну деталь базового: class="card card--hit".
Каскад
Порядок, в котором браузер решает, какое из конкурирующих правил применить.
Специфичность
«Вес» селектора. Чем конкретнее селектор, тем выше шанс победить: тег < класс < id < атрибут style.
Перечёркнутое правило
В панели Styles: правило, проигравшее в каскаде. Главная подсказка при отладке.
!important
Способ протолкнуть объявление вперёд всех. Признак того, что каскад не разобран. На курсе — только с объяснением педагогу.
Наследование
Часть свойств переходит от родителя к детям. Наследуются свойства текста, не наследуются отступы, рамки и фон.
inherit
Значение «возьми у родителя». Нужно полям формы и кнопкам, которые шрифт не наследуют.
CSS-переменная (токен)
Своё имя для значения: --pie-accent: #7cc142. Объявляется один раз, используется везде.
:root
Селектор корня документа, то есть тега <html>. Место, где объявляют переменные.
var()
Способ подставить значение переменной: color: var(--pie-accent).
data-атрибут
Собственный атрибут разработчика. Браузер его не трактует, но по нему можно писать селекторы и читать из JavaScript.
Тёмная тема
Второй набор значений тех же переменных в селекторе html[data-theme="dark"]. Правила при этом не дублируются.
Контраст
Разница яркости текста и фона. Для основного текста должен быть не ниже 4.5:1.
