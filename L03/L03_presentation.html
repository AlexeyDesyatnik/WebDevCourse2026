►► ПОНЯТИЕ

Форма — единственное место, где данные идут к тебе

  • Всё остальное на странице — витрина
  • Формой пользуются в спешке, с телефона, иногда без мыши
  • У пользователя нельзя просить лишние данные — каждое поле надо уметь обосновать

►► ЖИВОЙ КОД

Устройство формы

Форма оборачивает всё. Внутри — пары «подпись + поле» и кнопка в конце

<form>
  <label for="name">Имя</label>
  <input type="text" id="name">
  <button type="submit">Записаться</button>
</form>

►► ПОНЯТИЕ

Тип поля выбирают по смыслу данных

  • text — строка
  • tel — телефон, на мобильном откроет цифры
  • time — время, покажет удобный выбор
  • number с min и max — число в границах
<input type="time" id="time">
<input type="number" min="1" max="5">

►► ТАК НЕЛЬЗЯ

placeholder вместо подписи

►► ТАК НЕЛЬЗЯ

Подсказка исчезает при первом же символе. Через два поля человек уже не помнит, что было в первом. Программа чтения её может не прочитать вовсе

<input type="text" placeholder="Имя">
<input type="text" placeholder="Класс">

►► ВОПРОС

Как за одну секунду проверить, что подпись связана с полем?

Обсуждаем вслух. Ответ не показываем

►► ПОНЯТИЕ

Выбор из вариантов

  • <select> — один из многих, вариантов больше пяти
  • Переключатели — один из двух-четырёх, все видны
  • Флажки — сколько угодно или ни одного
  • У переключателей одной группы одинаковый name
<input type="radio" name="slot" value="bigbreak">
<input type="radio" name="slot" value="after">

Кнопка, до которой нельзя дойти, — это не кнопка

►► ТАК НЕЛЬЗЯ

Кнопка из <div>

►► ТАК НЕЛЬЗЯ

Не получает фокус клавишей Tab. Не нажимается Enter и пробелом. Программа чтения не объявит её кнопкой

<div class="btn" onclick="send()">
  Записаться
</div>

►► ПОНЯТИЕ

Таблица — для данных, не для раскладки

  • <caption> — подпись, что за данные
  • <th scope="col"> — заголовок столбца
  • <th scope="row"> — заголовок строки
  • <td> — обычная ячейка
<table>
  <caption>Часы работы</caption>
  <thead>
    <tr>
      <th scope="col">День</th>
      <th scope="col">Открыт</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">Суббота</th>
      <td>9:00 — 13:00</td>
    </tr>
  </tbody>
</table>

►► ПОНЯТИЕ

alt — не подпись, а замена картинки

  • Картинка что-то сообщает → описываем содержимое
  • Картинка декоративная → пустой alt=""
  • Слово «картинка» в alt не пишем никогда
<img src="pie.svg"
     alt="Брусничный пирог с решётчатой корочкой">

►► ИИ НА ЗАНЯТИИ

Промпт: проверка формы на доступность

Ты проверяешь HTML-форму начинающего верстальщика на доступность.
Контекст: форма предзаказа для школьного буфета. Только HTML, без CSS и JavaScript. Данные никуда не отправляются: это учебная страница. Уровень автора — третье занятие курса.
Задача: проверь мою форму и найди места, где человеку с программой чтения вслух или без мыши будет неудобно или невозможно ей пользоваться.
Ограничения: не переписывай форму целиком; не предлагай CSS, JavaScript, библиотеки и aria-атрибуты — их мы ещё не проходили; не предлагай добавлять новые поля; пиши по-русски.
Формат ответа: нумерованный список, не больше шести пунктов. В каждом: что не так → кому именно это мешает → как исправить одной строкой кода.
Критерии проверки: каждый пункт относится к строке, которая есть в моей форме; исправление — валидный HTML; ничего не выдумано сверх моего кода.

Глоссарий занятия 3

Форма
Блок для передачи данных от человека: поля, выбор вариантов, кнопка отправки.
<form>
Тег, оборачивающий форму целиком. Всё, что внутри, отправляется вместе.
<input>
Поле ввода одного значения. Вид зависит от атрибута type.
type
Атрибут, задающий вид поля: text, tel, email, date, time, number, radio, checkbox.
<label>
Подпись к полю. Связывается с ним через for и id. Обязательна всегда.
for и id
Пара атрибутов, связывающая подпись с полем. Должны совпадать полностью.
placeholder
Серая подсказка внутри пустого поля. Исчезает при вводе. Подписью не является.
required
Атрибут «поле обязательно». Браузер не даст отправить форму, пока оно пустое.
<select> и <option>
Выпадающий список и его вариант. value уходит с формой, текст видит человек.
Переключатели (type="radio")
Выбор одного варианта из нескольких. Группу задаёт одинаковый name.
Флажок (type="checkbox")
Самостоятельная отметка: включена или нет.
<textarea>
Большое поле для длинного текста.
<button>
Настоящая кнопка: получает фокус клавишей Tab, нажимается Enter и пробелом.
type="submit"
Тип кнопки, отправляющей форму. Поведение по умолчанию внутри <form>.
name
Имя поля при отправке данных. У переключателей одной группы — общее.
<table>
Таблица. Для данных со строками и столбцами, не для раскладки страницы.
<caption>
Подпись таблицы. Первая строка внутри <table>.
<thead> и <tbody>
Шапка таблицы с заголовками и её тело с данными.
<tr>
Одна строка таблицы.
<th>
Ячейка-заголовок. scope="col" — заголовок столбца, scope="row" — заголовок строки.
<td>
Обычная ячейка с данными.
<figure> и <figcaption>
Картинка вместе с видимой подписью.
