Эталонное решение

Стили живут в соседнем style.css, пути — только имена файлов. Слэш в начале уводит запрос в корень сайта, путь с C: существует только на твоём диске. У <link> обязателен rel="stylesheet", иначе браузер молча пропустит строку. Скрипт — последний элемент body, чтобы к моменту выполнения разметка уже была.


  


  

    
Глоссарий занятия

    

      
Относительный путь

      
Имя файла от текущей страницы: style.css, без слэша и без диска.

      
Деплой

      
Файлы лежат на сервере и открываются по адресу https://…, а не через file://.

      
Путь от корня

      
/style.css ищет файл в корне сайта, минуя папку проекта — после публикации будет 404.

      
Регистр имени

      
Windows не различает Pie.SVG и pie.svg, сервер различает.
