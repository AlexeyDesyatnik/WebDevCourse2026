►► ПОНЯТИЕ

Массив: список значений

  • Квадратные скобки, значения через запятую
  • Индекс с нуля: первый — нулевой
  • length — длина; последний — length - 1
  • Количество нигде не зашито
const prices = [45, 50, 90, 70, 85, 60];
prices[0];      // 45
prices.length;  // 6

►► ПОНЯТИЕ

Объект: одна вещь целиком

  • Фигурные скобки, пары «имя: значение»
  • Через точку — когда имя известно
  • Через скобки — когда имя в переменной
const rybnik = {
  name: "Рыбник",
  price: 90,
  kind: "солёное"
};
rybnik.price;  // 90

►► ЖИВОЙ КОД

Массив объектов

  • Список однотипных анкет
  • Сначала индекс, потом свойство
  • Набор свойств одинаков у всех
const PIES = [
  { id: "rybnik", name: "Рыбник", price: 90, kind: "солёное" },
  { id: "brusnika", name: "Брусничный пирог", price: 70, kind: "сладкое" }
];
PIES[0].name;   // "Рыбник"

Параллельные массивы

►► ТАК НЕЛЬЗЯ

Связь держится только на совпадении индексов. Отсортировали один — и цена рыбника досталась калитке. Найти такую ошибку почти невозможно

const names  = ["Калитка", "Рыбник"];
const prices = [45, 90];

►► ЖИВОЙ КОД

filter: отобрать нужное

  • Возвращает новый массив
  • Исходный не меняется
  • Ничего не подошло — пустой массив [], не undefined
  • Результат обязательно присваиваем
const sweet = PIES.filter((pie) => pie.kind === "сладкое");
sweet.length;   // 3
PIES.length;    // по-прежнему 6

►► ЖИВОЙ КОД

map и join: преобразовать и склеить

  • map — длина результата та же
  • join(", ") — склеить в строку
  • Методы ставятся цепочкой, читается сверху вниз
PIES
  .filter((pie) => pie.kind === "сладкое")
  .map((pie) => pie.name)
  .join(", ");

►► ВОПРОС

Чем filter отличается от find?

Обсуждаем вслух. Подсказка: дело в том, что возвращается

►► ПОНЯТИЕ

find: один элемент

  • Возвращает первый подходящий, не массив
  • Не нашёл — undefined
  • Обращение к свойству у undefined роняет программу
  • Результат проверяем
const pie = PIES.find((p) => p.id === "rybnik");
if (pie === undefined) {
  console.log("Такого пирога нет");
}

►► ТАК НЕЛЬЗЯ

sort() без функции сравнения

►► ТАК НЕЛЬЗЯ

Сто меньше сорока пяти? Он сравнил как строки: «100» начинается с единицы

[45, 100, 90, 8].sort();
// [100, 45, 8, 90]

►► ЖИВОЙ КОД

Две ловушки sort

  • Для чисел — функция сравнения (a, b) => a - b
  • sort меняет исходный массив, в отличие от filter и map
  • Поэтому сначала копия: [...pies]
const copy = [...pies];
copy.sort((a, b) => a.price - b.price);

►► ЗАЧЕМ

Четыре метода — четыре вопроса

  • Нужен список подходящих → filter
  • Нужен список преобразованных → map
  • Нужен один элемент → find
  • Нужен порядок → sort (с копией и сравнением)

►► ИИ НА ЗАНЯТИИ

Промпт: объясни разницу методов на жизненном примере

Ты объясняешь концепции программирования подростку 14 лет на жизненных примерах.
Контекст: ученик второй недели изучения JavaScript. Знает переменные, типы, функции, условие. Сегодня разбирает массивы объектов и методы `filter`, `map`, `find`, `sort`.
Задача: объясни разницу между `filter`, `map` и `find` на одном сквозном жизненном примере — не на коде и не на массивах.
Ограничения: пример должен быть один и тот же для всех трёх методов; не используй слова «массив», «элемент», «функция» внутри самого примера; не пиши код; не бери примеры про сортировщик почты и про конвейер — они уже разобраны на занятии; не длиннее трёх предложений на метод.
Формат ответа: сначала описание ситуации в двух предложениях, потом три абзаца — по одному на метод. В каждом абзаце отдельной строкой: что получится на выходе и сколько штук.
Критерии проверки: пример один на все три метода; из объяснения ясно, что `filter` может вернуть меньше, `map` — столько же, `find` — одну штуку или ничего.

Проверить руками: пример один на три метода · верно про количество на выходе · сказано про «ничего» у find · нет слов «массив» и «элемент» внутри примера · понял бы одноклассник · кода нет

Правило курса: сдаётся только то, что ты можешь объяснить

Глоссарий занятия 9

Массив
Упорядоченный список значений в квадратных скобках.
Индекс
Номер элемента в массиве. Отсчёт с нуля; последний элемент имеет индекс length - 1.
length
Количество элементов в массиве.
Объект
Набор пар «имя — значение» в фигурных скобках. Описывает одну вещь.
Свойство (ключ)
Одна пара внутри объекта.
Запись через точку
Обращение к свойству по известному имени: pie.price.
Запись через квадратные скобки
Обращение по имени, лежащему в переменной: pie[field].
Массив объектов
Список однотипных записей. Главная структура данных курса.
forEach
Пройти по каждому элементу и что-то сделать. Результат не возвращает.
filter
Построить новый массив из подходящих элементов. Исходный не меняет. Ничего не подошло — пустой массив.
map
Построить новый массив, преобразовав каждый элемент. Длина результата равна исходной.
find
Вернуть первый подходящий элемент. Не нашёл — undefined.
join
Склеить массив в строку через указанный разделитель.
sort
Упорядочить массив. Меняет исходный массив, поэтому перед ним делают копию.
Функция сравнения
То, что передают в sort для чисел: (a, b) => a - b. Возвращает число, а не логическое значение.
Копия массива [...arr]
Новый массив с теми же элементами. Делается перед сортировкой, чтобы не испортить исходный.
Безымянная функция
Функция без имени, переданная прямо в метод: pies.filter((pie) => pie.kind === "сладкое").
Цепочка методов
Запись, где результат одного метода идёт на вход следующему: .filter().map().join().
