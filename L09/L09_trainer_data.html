Заказ

Заказ буфета «Северный пирог». Научись доставать из данных то, что нужно.

Как сделать кодом

  • getSweet(pies) — вернуть только сладкие
  • getNames(pies) — вернуть массив названий
  • sortByPrice(pies) — вернуть новый массив по возрастанию цены, не испортив исходный

Самопроверка

Подсказки

Три подсказки. На демо — своими словами.

Для каждой функции спроси себя: что должно получиться на выходе — список, один элемент или строка? Список подходящих — filter. Список преобразованных — map. Один элемент — find. Строка — map плюс join.
filter и map создают новый массив и возвращают его — результат надо вернуть через return. sort меняет массив на месте, поэтому перед ним делают копию [...pies], а для чисел нужна функция сравнения (a, b) => a.price - b.price. find возвращает один элемент или undefined — результат проверяй.
function getSweet(pies) {
  return pies.filter((pie) => pie.kind === "сладкое");
}

function sortByPrice(pies) {
  const copy = [...pies];
  return copy.sort((a, b) => a.price - b.price);
}

function getById(pies, id) {
  const found = pies.find((pie) => pie.id === id);
  if (found === undefined) {
    return null;
  }
  return found;
}

Эталонное решение

Откроется, когда все проверки зелёные или открыты три подсказки.

Почему так: filter и map не трогают исходный массив — но результат надо вернуть. sort переставляет элементы на месте, поэтому сначала копия. find даёт один элемент или undefined: без проверки программа упадёт. Пустой список — понятная строка, не пустота.


      

    


    

      
Глоссарий занятия

      

        
filter

        
Новый массив из подходящих. Исходный не меняет.

        
map

        
Новый массив той же длины: каждый элемент преобразован.

        
find

        
Первый подходящий элемент. Не нашёл — undefined.

        
sort

        
Упорядочивает массив на месте. Сначала копия [...arr].

        
join

        
Склеить массив в строку через разделитель.
