ТЗ

Заказ буфета «Северный пирог».
Собери UI-кит: кнопку, карточку, пилюлю. Так, чтобы ими мог пользоваться любой человек.

  • Кнопка: базовый класс .btn плюс модификаторы, три состояния
  • Фокус виден: :focus-visible со своей обводкой. outline: none без замены запрещён
  • Переходы плавные: transition в базовом правиле, не в :hover
  • Карточка: базовая и «хит», у хита есть пилюля со словом
  • Ровно одна анимация появления
  • Блок prefers-reduced-motion в конце файла

Как сделать кодом

  1. .btn — форма, font-family: inherit, transition.
  2. Модификаторы .btn--primary и .btn--ghost — только цвет.
  3. Состояния: :hover, :focus-visible с outline, :active.
  4. .card + .card--hit, пилюля со словом, @keyframes и reduced-motion.

Как сделать блоками

Слева блоки CSS, справа поля. Чип ставится кликом, перетаскиванием или клавишей Enter.

Эталон-цель

Две кнопки с состояниями. Хит — пилюлей, не только цветом. Одна анимация появления.

Результат

Самопроверка

Состояния :hover / :focus-visible / :active — по исходному CSS. Остальное — getComputedStyle в iframe.

Подсказки

Три подсказки. На демо — своими словами.

Пройди свою кнопку тремя способами: наведи мышь, нажми Tab, нажми и подержи. Все три раза что-то изменилось? Тот способ, где ничего не произошло, и есть недостающее состояние.
Кнопка: .btn — форма, размер, font-family: inherit, transition. .btn--primary и .btn--ghost — только цвет. Ниже три состояния: :hover меняет фон, :focus-visible даёт outline с outline-offset, :active сдвигает на пиксель. Карточка: .card плюс .card--hit, и у хита пилюля со словом. В конце — @keyframes и блок prefers-reduced-motion.
.btn {
  font-family: inherit;
  padding: 12px 24px;
  border-radius: 999px;
  border: 2px solid transparent;
  cursor: pointer;
  transition: background 160ms ease, color 160ms ease;
}
.btn:hover { background: var(--pie-accent-dark); color: #fff; }
.btn:focus-visible {
  outline: 3px solid var(--pie-accent-dark);
  outline-offset: 3px;
}
.btn:active { transform: translateY(1px); }

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: .01ms !important;
    transition-duration: .01ms !important;
  }
}

Эталонное решение

Откроется, когда все проверки зелёные или открыты три подсказки.

Почему так: База .btn держит форму и transition — иначе увод мыши будет рывком. Модификаторы меняют только цвет. :focus-visible заменяет, а не убирает обводку. Хит дублируется словом на пилюле. prefers-reduced-motion уважает настройку системы.


      

    


    

      
Глоссарий занятия

      

        
transition

        
Плавная смена свойства. Пишется в базовом правиле, не в :hover.

        
@keyframes

        
Сценарий кадров. Имя потом в animation.

        
:focus-visible

        
Обводка при навигации с клавиатуры.

        
.btn--primary / .btn--ghost

        
Модификаторы: одно отличие поверх базы.

        
prefers-reduced-motion

        
Укоротить анимации, если система просит меньше движения.
