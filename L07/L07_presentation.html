Скругления разные, отступы разные, цвета близкие, но не совпадают. Никто этого не хотел — просто писали в разное время

►► ПОНЯТИЕ

Компонент: базовый класс плюс модификатор

  • .btn — форма, размер, шрифт, поведение
  • .btn--primary, .btn--ghost — только цвет
  • Два класса через пробел в разметке
  • Имя по роли, не по цвету
<button class="btn btn--primary">
.btn { padding: 12px 24px; }
.btn--primary { background: var(--pie-accent); }

►► ПОНЯТИЕ

Три состояния кнопки

  • :hover — курсор наведён. На телефоне не срабатывает
  • :focus-visible — фокус с клавиатуры. Обязателен всегда
  • :active — момент нажатия
.btn:hover { background: var(--pie-accent-dark); }
.btn:focus-visible { outline: 3px solid var(--pie-accent-dark); }
.btn:active { transform: translateY(1px); }

Сейчас я сделаю страницу непригодной одной строкой

►► ТАК НЕЛЬЗЯ

outline: none

►► ТАК НЕЛЬЗЯ

Стандартная обводка кажется некрасивой, и её убирают. Результат: человек, который ходит по странице клавишей Tab, перестаёт видеть, где находится

.btn:focus { outline: none; }

Не нравится — замени, а не убирай

.btn:focus-visible {
  outline: 3px solid var(--pie-accent-dark);
  outline-offset: 3px;
}

►► ЖИВОЙ КОД

transition: плавность вместо рывка

  • Пишется в базовом правиле, не в :hover
  • 120–250 мс. Стандарт для ховера — 160
  • Анимируется не всё: display нельзя, opacity и transform можно
.btn {
  transition: background 160ms ease;
}
.btn:hover { background: var(--pie-accent-dark); }

►► ЖИВОЙ КОД

@keyframes: анимация по кадрам

  • Что в начале, что в конце — промежуточное рисует браузер
  • both — сохраняй значения до старта и после финиша
  • animation-delay разной величины даёт «лесенку»
@keyframes fade-up {
  from { opacity: 0; transform: translateY(12px); }
  to   { opacity: 1; transform: translateY(0); }
}

►► ТАК НЕЛЬЗЯ

Когда движется всё

►► ТАК НЕЛЬЗЯ

Пять анимаций, четыре бесконечные. Читать тяжело, на школьной машине подтормаживает. И ни одна ничего не сообщает

Норма: две-три на страницу. Бесконечная — только индикатор ожидания

.btn  { animation: shake 500ms infinite; }
.pill { animation: pulse 700ms infinite; }
.top  { animation: rainbow 4s infinite; }

►► ЗАЧЕМ

Есть люди, которым движение неприятно

  • От раздражения до тошноты и головокружения
  • В системе есть настройка «уменьшить движение»
  • Из CSS она видна как медиазапрос
  • Шесть строк в конец файла — и интерфейс подходит всем
@media (prefers-reduced-motion: reduce) {
  * { animation-duration: .01ms !important; }
}

►► ПОНЯТИЕ

Цвет не может быть единственным сигналом

  • Хит только зелёной рамкой — человек, не различающий цвета, увидит две одинаковые карточки
  • Нужно дублирование: слово, значок, форма
  • Пилюля со словом «Хит недели» — от 13–14 пикселей
<span class="pill">Хит недели</span>

►► ИИ НА ЗАНЯТИИ

Промпт: три SVG-иконки в едином стиле

Ты рисуешь SVG-иконки для учебного веб-проекта.
Контекст: страница школьного буфета «Северный пирог». Только HTML и CSS, без библиотек и без внешних файлов — иконка вставляется прямо в разметку. Цвета берутся из CSS-переменных страницы.
Задача: нарисуй три иконки в едином стиле — пирог, часы, галочка. Стиль контурный, толщина линии одинаковая.
Ограничения: обязательно `viewBox="0 0 24 24"`; без атрибутов `width` и `height` в разметке; `fill="none"` и `stroke="currentColor"`; `stroke-width="2"`; не больше трёх элементов `path` или `circle` на иконку; никаких `<style>`, `<title>`, `id`, `xmlns:xlink` и атрибутов графических редакторов; никаких градиентов и фильтров.
Формат ответа: три блока кода, перед каждым — название иконки одной строкой. Ниже — таблица: иконка, где применяется, нужен ли ей `aria-hidden`.
Критерии проверки: каждая иконка масштабируется от 16 до 64 пикселей без искажений; цвет управляется свойством `color` родителя; в коде нет ничего, кроме `svg`, `path` и `circle`.

Проверить руками: есть viewBox · нет width/height в разметке · цвет через currentColor · нет мусорных атрибутов и <title> · проверено на трёх размерах · похоже на заявленное

Правило курса: сдаётся только то, что ты можешь объяснить

Глоссарий занятия 7

Компонент
Самостоятельный кусочек интерфейса с именем, который переиспользуется: кнопка, карточка, поле, метка.
UI-кит
Набор компонентов проекта, описанный один раз и применяемый везде.
Базовый класс
Правило компонента с тем, что общее для всех его экземпляров: .btn.
Модификатор
Дополнительный класс, меняющий одну характеристику базового: .btn--primary.
Состояние
Вид элемента в зависимости от того, что с ним происходит. Задаётся псевдоклассом.
:hover
Состояние «курсор наведён». На телефоне не срабатывает.
:focus-visible
Состояние «элемент получил фокус с клавиатуры». Подсветку убирать нельзя.
:active
Состояние «элемент нажат и удерживается».
outline
Обводка, рисуемая поверх элемента. Не занимает места и не сдвигает соседей, в отличие от border.
outline-offset
Отступ обводки от края элемента.
transition
Плавный переход свойства из одного значения в другое. Пишется в базовом правиле, а не в состоянии.
transform
Сдвиг, поворот, масштаб элемента. Не пересчитывает раскладку и не двигает соседей.
@keyframes
Описание анимации по кадрам: что в начале, что в конце.
animation
Назначение анимации элементу: имя, длительность, характер, режим заполнения.
animation-delay
Задержка перед стартом. Разные задержки у соседей дают эффект «лесенки».
infinite
Бесконечное повторение анимации. Оправдано только для индикатора ожидания.
prefers-reduced-motion
Медиазапрос, читающий системную настройку «уменьшить движение». Обязателен в любом проекте с анимациями.
Пилюля (тег, бейдж)
Маленькая метка со скруглением, обозначающая свойство: «хит», «новинка». Всегда содержит текст, а не только цвет.
currentColor
Значение «цвет текста родителя». В SVG позволяет иконке менять цвет вместе с темой.
viewBox
Система координат SVG. Без него картинка не масштабируется.
aria-hidden="true"
Атрибут «скрыть от программы чтения». Ставится декоративным иконкам рядом с текстом.
aria-label
Текстовая подпись элемента для программы чтения. Обязательна кнопке, у которой только иконка.
