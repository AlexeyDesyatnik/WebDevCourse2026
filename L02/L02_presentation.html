►► ЗАКАЗ

Марина Петровна и очередь на двадцать человек

Школьный буфет «Северный пирог». На большой перемене очередь, и половина стоит просто посмотреть, что сегодня есть. Заказ: страница, где меню видно заранее

►► КРЮЧОК

Вот текст. Браузер его не понял

Слева — текст от заказчика. Справа — как это выглядит в браузере: одна слипшаяся строка

Северный пирог
Меню на сегодня
Калитка с картошкой 45

►► ПОНЯТИЕ

HTML отвечает на вопрос «что это», а не «как выглядит»

  • Ты не пишешь программу — ты размечаешь готовый текст
  • Ставишь пометку: это заголовок, это абзац, это список
  • Как показывать, браузер решает сам

►► ЖИВОЙ КОД

Тот же текст, но размеченный

Ни одного правила оформления — а страница уже читается

<h1>Северный пирог</h1>
<ul>
  <li>Калитка с картошкой — 45 ₽</li>
  <li>Рыбник — 90 ₽</li>
</ul>

►► ТАК НЕЛЬЗЯ

Разделять смысл переносами строк

►► ТАК НЕЛЬЗЯ

Визуально похоже. Смысла ноль: заголовков нет, списка нет, стилизовать нечего

Северный пирог<br><br>
Калитка с картошкой — 45 ₽<br>
Рыбник — 90 ₽<br>

►► ПОНЯТИЕ

Каркас документа

  • <!DOCTYPE html> — это современный HTML
  • <html lang="ru"> — язык документа
  • <head> — для браузера: кодировка, название вкладки
  • <body> — для человека: всё, что видно
<!DOCTYPE html>
<html lang="ru">
<head>
<meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
<title>Северный пирог</title>
</head>
<body>

</body>
</html>

►► ПОНЯТИЕ

Заголовок — это уровень, а не размер

  • <h1> один на странице: о чём она вся
  • Уровни не перепрыгиваются: 1 → 2 → 3
  • Нужен текст покрупнее — это CSS, одна строка
<h1>Северный пирог</h1>
<h2>Меню на сегодня</h2>
<h3>Солёное</h3>

Теперь тег, который не меняет ровно ничего

►► ЖИВОЙ КОД

Четыре тега, которые называют куски страницы

  • <header> — шапка
  • <main> — основное, ровно один
  • <section> — смысловая секция, обязательно с заголовком
  • <footer> — подвал
<header>
  <h1>Северный пирог</h1>
</header>
<main>
  <section>
    <h2>Меню на сегодня</h2>
  </section>
</main>

►► ВОПРОС

Ничего не изменилось. Зачем я это писал?

Обсуждаем вслух. Ответ не показываем — его должна дать группа

►► ЗАЧЕМ

Три проверки, где разница видна

  • Режим чтения — браузер строит его по вашим тегам
  • Навигация без мыши — прыжки по заголовкам и сразу к main
  • Поиск — понимает, о чём страница

Плюс: через месяц вы сами разберётесь в своём коде

►► ТАК НЕЛЬЗЯ

div-суп

►► ТАК НЕЛЬЗЯ

Снаружи похоже на страницу. Внутри — неразличимая масса: ни заголовков, ни списка, ни основного содержимого

<div class="header">
  <div class="title">Северный пирог</div>
</div>
<div class="item">Калитка — 45 ₽</div>

►► ИИ НА ЗАНЯТИИ

Промпт: ИИ как проверяющий, а не как автор

Ты проверяешь HTML-разметку начинающего верстальщика на семантику и доступность.
Контекст: страница школьного буфета, только HTML, без CSS и JavaScript. Уровень автора — вторая неделя обучения.
Задача: проверь разметку, которую я приложу, и найди места, где выбран неподходящий по смыслу тег или нарушена доступность.
Ограничения: не переписывай мой код целиком; не предлагай CSS, JavaScript и библиотеки; не добавляй теги, для которых у меня нет содержимого; пиши по-русски.
Формат ответа: таблица из трёх колонок — строка моего кода, что не так, чем заменить. Не больше семи строк.
Критерии проверки: каждое замечание относится к конкретной строке; для каждого объяснено, кому именно это мешает; ничего не выдумано сверх того, что есть в моём коде.

Вот моя разметка:
[вставь сюда свой код]

Проверить руками: замечание про реальную строку · предложенный тег существует · нет пустых nav/article · объяснено, кому мешает · страница не сломалась · ты сам согласен

Правило курса: сдаётся только то, что ты можешь объяснить

Глоссарий занятия 2

HTML
Язык разметки. Им ты объясняешь браузеру, что на странице заголовок, что абзац, а что список.
Разметка
Расстановка тегов вокруг текста, чтобы у него появился смысл.
Тег
Команда разметки в угловых скобках: <p>, <h1>, <main>.
Парный тег
Тег с открывающей и закрывающей частью: <p>текст</p>.
Одиночный тег
Тег без закрывающей части: <img>, <br>.
Элемент
Тег вместе с содержимым внутри.
Атрибут
Дополнение к тегу, пишется в открывающем теге: lang="ru", alt="…".
Вложенность
Элементы внутри элементов. Открыли снаружи — закрываем изнутри.
DOCTYPE
Первая строка файла. Говорит браузеру: это современный HTML.
Семантика
Выбор тега по смыслу содержимого, а не по внешнему виду.
<header>
Шапка страницы или блока.
<main>
Основное содержимое страницы. На странице ровно один.
<section>
Смысловая секция. Без заголовка внутри не имеет смысла.
<footer>
Подвал: контакты, служебные сведения.
<div>
Контейнер без смысла. Берётся, когда нужен просто ящик для оформления.
<span>
То же, что div, но внутри строки текста.
<ul> и <li>
Маркированный список и его пункт.
<h1>–<h6>
Заголовки шести уровней. Уровень — это место в иерархии, а не размер.
alt
Текстовое описание картинки. Читается вслух и показывается, если картинка не загрузилась.
Доступность
Свойство страницы быть понятной всем, включая тех, кто пользуется программой чтения вслух или только клавиатурой.
Скринридер
Программа, читающая страницу вслух. Ориентируется по семантическим тегам и заголовкам.
Режим чтения
Встроенная в браузер функция, превращающая страницу в чистый текст. Работает по семантическим тегам.
div-суп
Разметка, состоящая из одних контейнеров без смысла.
