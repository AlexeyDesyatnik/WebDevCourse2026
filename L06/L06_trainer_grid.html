ТЗ

Заказ буфета «Северный пирог».
Сделай меню, которое нормально смотрится с телефона.

  • Меню — сетка на Grid, ширина колонок в fr
  • На узком экране одна колонка, от 600 — две, от 900 — три
  • Пиши по Mobile First: базовые правила для телефона, расширения через min-width
  • Медиазапросы в конце файла, по возрастанию ширины
  • Таблица часов работы не должна вылезать за край

Без max-width в медиазапросах и без процентов в колонках.

Как сделать кодом

  1. База: .menu { display: grid; grid-template-columns: 1fr; gap: 16px; }.
  2. От 600 px — repeat(2, 1fr), от 900 px — repeat(3, 1fr).
  3. Медиазапросы в конце, сначала 600, ниже 900.
  4. Обёртке таблицы — overflow-x: auto. Не прячь содержимое.

Как сделать блоками

Слева блоки CSS, справа поля. Чип ставится кликом, перетаскиванием или клавишей Enter.

Эталон-цель

Телефон — одна колонка. Планшет — две. Ноутбук — три. Таблица едет внутри себя.

Результат

Самопроверка

Сетка и gap — через getComputedStyle. Медиазапросы и порядок — по исходному CSS: превью одной ширины.

Подсказки

Три подсказки. На демо — своими словами.

С какого экрана ты начинаешь? Посмотри на свои базовые правила: если раскомментировать только их, как страница будет выглядеть на телефоне? И второй вопрос: в каком порядке у тебя написаны медиазапросы?
Базовое правило: display: grid; grid-template-columns: 1fr; gap: 16px;. Дальше два блока в конце файла: @media (min-width: 600px) с repeat(2, 1fr), ниже @media (min-width: 900px) с repeat(3, 1fr). Таблице — обёртка с overflow-x: auto.
.menu {
  display: grid;
  grid-template-columns: 1fr;
  gap: 16px;
}

.table-wrap { overflow-x: auto; }

@media (min-width: 600px) {
  .menu { grid-template-columns: repeat(2, 1fr); gap: 20px; }
}

@media (min-width: 900px) {
  .menu { grid-template-columns: repeat(3, 1fr); }
}

Эталонное решение

Откроется, когда все проверки зелёные или открыты три подсказки.

Почему так: База — одна колонка, потому что Mobile First. Медиазапросы по возрастанию: на широком экране истинны оба, побеждает нижний. Проценты плюс gap вылезают за край. Таблицу не прячем — даём прокрутку обёртке.


      

    


    

      
Глоссарий занятия

      

        
Grid

        
Двумерная сетка: display: grid на родителе.

        
fr

        
Доля свободного места после промежутков.

        
@media

        
Правила при условии. Здесь — ширина окна.

        
Mobile First

        
База для узкого экрана, расширения через min-width.

        
overflow-x: auto

        
Прокрутка широкой таблицы внутри обёртки.
