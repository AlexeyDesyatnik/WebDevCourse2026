►► ПОНЯТИЕ

Flexbox одномерный, Grid двумерный

  • Flexbox — вдоль одной линии: шапка, ряд кнопок, форма
  • Grid — строки и колонки сразу: сетка карточек, раскладка страницы
  • Вопрос для выбора: важно ли, что происходит по обеим осям?

►► ЖИВОЙ КОД

Колонки и доля fr

  • display: grid — контейнеру
  • 1fr — одна доля свободного места
  • repeat(3, 1fr) — то же, что 1fr 1fr 1fr
  • gap — тот же, что во Flexbox
.menu {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}

►► ТАК НЕЛЬЗЯ

Проценты вместо fr

►► ТАК НЕЛЬЗЯ

33% × 3 плюс два промежутка по 20 — больше ста процентов. Последняя колонка вылезет за край

.menu {
  display: grid;
  grid-template-columns: 33% 33% 33%;
  gap: 20px;
}

Одна строка вместо трёх медиазапросов

►► ЖИВОЙ КОД

Сетка, которая считает себя сама

  • minmax(220px, 1fr) — не уже 220, но растягивается
  • auto-fit — столько колонок, сколько влезет
  • 4 → 3 → 2 → 1 без единого медиазапроса
.menu {
  display: grid;
  grid-template-columns:
    repeat(auto-fit, minmax(220px, 1fr));
  gap: 20px;
}

►► ПОНЯТИЕ

Медиазапрос: правила с условием

  • @media (min-width: 600px) — «если не уже 600»
  • На курсе только min-width
  • Пишутся в конце файла
  • Идут по возрастанию ширины
@media (min-width: 600px) {
  .menu { grid-template-columns: repeat(2, 1fr); }
}

►► ТАК НЕЛЬЗЯ

Медиазапросы в обратном порядке

►► ТАК НЕЛЬЗЯ

На широком экране истинны оба условия. Побеждает написанный ниже — три колонки не появятся никогда. Ни ошибки, ни предупреждения

@media (min-width: 900px) {
  .menu { grid-template-columns: repeat(3, 1fr); }
}

@media (min-width: 600px) {
  .menu { grid-template-columns: repeat(2, 1fr); }
}

►► ВОПРОС

Почему медиазапрос, написанный в начале файла, не работает?

►► ПОНЯТИЕ

Mobile First

  • Базовые правила — для узкого экрана
  • Расширения — через min-width
  • Правила накапливаются, а не отменяются
  • Узкий экран — сложный случай, широкий — простой
/* база: телефон */
.menu { grid-template-columns: 1fr; }
@media (min-width: 600px) {
  .menu { grid-template-columns: repeat(2, 1fr); }
}

►► ЖИВОЙ КОД

Раскладку видно прямо в коде

grid-template-areas — схема словами. Одно имя в соседних клетках объединяет их. Порядок в разметке при этом не меняется

.layout {
  display: grid;
  grid-template-areas:
    "head head"
    "main side"
    "foot foot";
}

►► ИИ НА ЗАНЯТИИ

Промпт: параметры адаптивной сетки

Ты подбираешь параметры адаптивной сетки для учебного веб-проекта.
Контекст: страница школьного буфета, сетка карточек с пирогами. Только HTML и CSS, без библиотек. В проекте используется CSS Grid для сеток и Flexbox для рядов. Подход Mobile First: базовые правила для узкого экрана, расширения через `min-width`. Уровень автора — шестое занятие курса.
Задача: предложи параметры сетки меню так, чтобы на телефоне была одна колонка, на планшете две, на ноутбуке три. Дай два варианта: первый без медиазапросов, на `repeat(auto-fit, minmax(…))`; второй с медиазапросами.
Ограничения: только `min-width`, никаких `max-width`; ширина колонок в `fr`, не в процентах; никакого `float`, `position: absolute` и библиотек; самый узкий поддерживаемый экран — 360 пикселей.
Формат ответа: два блока CSS с комментариями на русском. Ниже — таблица: ширина экрана, число колонок, какой вариант её даёт.
Критерии проверки: минимальная ширина колонки меньше 360; медиазапросы идут по возрастанию ширины; ни в одном варианте нет `max-width` и процентов.

Проверить руками: минимум меньше 360 · медиазапросы по возрастанию · нет max-width · ширины в fr · проверено сужением до 360 · можешь объяснить auto-fit и minmax

Правило курса: сдаётся только то, что ты можешь объяснить

Глоссарий занятия 6

CSS Grid
Механизм раскладки по строкам и колонкам одновременно. Двумерный, в отличие от Flexbox.
Грид-контейнер
Элемент с display: grid. Правила пишутся ему, слушаются его прямыми детьми.
grid-template-columns
Свойство, задающее число и ширину колонок сетки.
fr
Единица «доля свободного места». 1fr 1fr 1fr — три равные колонки. Делит остаток после промежутков и фиксированных размеров.
repeat()
Сокращение для одинаковых колонок: repeat(3, 1fr) вместо 1fr 1fr 1fr.
minmax()
Задаёт границы колонки: не уже первого значения, не шире второго.
auto-fit
Вместо числа колонок: «сделай столько, сколько поместится».
grid-template-rows
То же, что grid-template-columns, но для строк.
grid-template-areas
Схема раскладки словами: каждая строка в кавычках — строка сетки, каждое слово — клетка.
grid-area
Свойство элемента: имя области, которую он занимает.
Медиазапрос
Блок правил, действующий при выполнении условия: @media (min-width: 600px).
min-width
Условие «ширина окна не меньше указанной». Единственный вид условий на курсе.
max-width
Условие «ширина окна не больше указанной». Признак подхода Desktop First, на курсе не используется.
Точка перелома
Ширина экрана, на которой меняется раскладка. Выбирается там, где ломается вёрстка, а не по моделям устройств.
Mobile First
Порядок работы: базовые правила для узкого экрана, расширения через min-width. Правила накапливаются, а не отменяются.
viewport
Строка <meta name="viewport" content="width=device-width, initial-scale=1"> в <head>. Без неё мобильный браузер уменьшает страницу целиком, и адаптив не работает.
overflow-x: auto
Горизонтальная прокрутка внутри блока. Способ показать широкую таблицу на телефоне, не ломая страницу.
Зона нажатия
Область, по которой можно попасть пальцем. Минимум примерно 44 на 44 пикселя.
