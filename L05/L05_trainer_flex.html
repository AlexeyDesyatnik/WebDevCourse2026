ТЗ

Заказ буфета «Северный пирог».
Собери раскладку страницы так, чтобы она не разъезжалась на телефоне.

  • Шапка: название слева, кнопка справа, выровнены по центру высоты
  • Меню: карточки в ряд, с равными промежутками, с переносом на узком экране
  • Карточки делят ширину между собой, фиксированных пикселей нет
  • Подвал прижат к низу окна
  • box-sizing: border-box первой строкой

Без float и без position: absolute.

Как сделать кодом

  1. Первой строкой — *, *::before, *::after { box-sizing: border-box; }.
  2. Шапке .top — ряд, space-between, align-items: center.
  3. Меню .menu — флекс, перенос, gap. Карточке — flex: 1 1 220px.
  4. Каркас: body колонкой на min-height: 100vh, main { flex: 1; }.

Как сделать блоками

Слева блоки CSS, справа поля. Чип ставится кликом, перетаскиванием или клавишей Enter.

Подсказки

Три подсказки. На демо — своими словами.

Кого ты расставляешь в ряд — и кто их общий родитель? Свойство display: flex пишется родителю. И второй вопрос: что произойдёт с твоими карточками, если сузить окно до ширины телефона?
Контейнеру ряда: display: flex, flex-wrap: wrap, gap. Карточке: flex: 1 1 220px вместо width. Шапке: justify-content: space-between вдоль ряда и align-items: center поперёк. Каркасу: body { min-height: 100vh; display: flex; flex-direction: column } и main { flex: 1 }.
*, *::before, *::after { box-sizing: border-box; }

body {
  margin: 0;
  min-height: 100vh;
  display: flex;
  flex-direction: column;
}
main { flex: 1; }

.top {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

.menu {
  display: flex;
  flex-wrap: wrap;
  gap: 20px;
}

.card { flex: 1 1 220px; }

Эталонное решение

Откроется, когда все проверки зелёные или открыты три подсказки.

Почему так: display: flex пишется родителю. gap не оставляет крайний отступ. flex: 1 1 220px делит ширину без фиксированных пикселей. Подвал прижимает main { flex: 1 } на колонке body, а не position: absolute.


      

    


    

      
Глоссарий занятия

      

        
Flexbox

        
Ряд или колонка: display: flex на родителе.

        
Основная ось

        
Вдоль неё работает justify-content.

        
gap

        
Промежуток у контейнера, не margin у детей.

        
flex-wrap

        
wrap — перенос, если ряд не влезает.

        
flex: 1 1 220px

        
Базовый размер 220 px с правом растянуться и сжаться.

        
box-sizing

        
border-box включает padding и рамку в ширину.
