►► ЗАКАЗ

Шесть пирогов на три экрана

Марина Петровна: «Хочется, чтобы пироги были рядом, а не столбиком на весь экран. И чтобы контакты были внизу, а не сразу под меню, когда пирогов мало»

►► ПОНЯТИЕ

Почему всё идёт столбиком

  • Блочные (div, p, li, section) — с новой строки, во всю ширину
  • Строчные (span, a, img) — в строке, по содержимому
  • Это нормальный поток: правило браузера по умолчанию
<div> — блочный
<span> — строчный

►► ПОНЯТИЕ

Блочная модель: элемент из четырёх слоёв

  • содержимое → padding → border → margin
  • По умолчанию width задаёт только содержимое
  • 200 + 16 + 16 + 2 + 2 = 236
.card {
  width: 200px;
  padding: 16px;
  border: 2px solid;
}

►► ЖИВОЙ КОД

Строка, которая ставится первой всегда

border-box означает: width — это итоговая ширина, вместе с отступами и рамкой

*, *::before, *::after {
  box-sizing: border-box;
}

Одна строка превращает столбик в ряд

►► ЖИВОЙ КОД

Flexbox: правила пишет контейнер

  • display: flex — родителю, не карточкам
  • Действует только на прямых детей
  • Дети перестают растягиваться на всю ширину
.menu { display: flex; }
.card { padding: 16px; }

►► ТАК НЕЛЬЗЯ

display: flex не тому элементу

►► ТАК НЕЛЬЗЯ

В ряд встанет содержимое карточки, а сами карточки останутся столбиком. Самая частая ошибка первого занятия по Flexbox

.card { display: flex; }

►► ПОНЯТИЕ

Две оси — и это почти весь Flexbox

  • justify-content — вдоль ряда: flex-start, center, flex-end, space-between
  • align-items — поперёк: stretch, center, flex-start, flex-end
  • stretch по умолчанию — поэтому карточки одинаковой высоты
.top {
  justify-content: space-between;
  align-items: center;
}

►► ВОПРОС

В шапке три элемента, а разнести надо на две группы. Как?

Название слева, ссылка и кнопка вместе справа. space-between разнесёт все три поровну

►► ЖИВОЙ КОД

gap вместо отступов у каждого

  • Пишется контейнеру
  • По краям ряда ничего не добавляет
  • Работает и между строками при переносе
.menu {
  display: flex;
  gap: 20px;
}

►► ЖИВОЙ КОД

Перенос и гибкость

  • flex-wrap: wrap — разрешить перенос
  • flex: 1 1 220px — базовый размер, право растянуться и сжаться
  • Шесть в ряд → три → две → одна. Без единого медиазапроса
.menu { flex-wrap: wrap; }
.card { flex: 1 1 220px; }

►► ТАК НЕЛЬЗЯ

Вёрстка «на глаз»

►► ТАК НЕЛЬЗЯ

Фиксированные пиксели, float, абсолютное позиционирование. На вашем мониторе идеально, на телефоне — горизонтальная прокрутка

.menu { width: 1000px; }
.card { width: 220px; float: left; }

►► ЖИВОЙ КОД

Подвал внизу: четыре строки

Каркас, который вы перенесёте в итоговый проект без изменений

body {
  min-height: 100vh;
  display: flex;
  flex-direction: column;
}
main { flex: 1; }

Промпт: проверка раскладки на узком экране

Ты проверяешь CSS-раскладку начинающего верстальщика.
Контекст: страница школьного буфета. Только HTML и CSS, без библиотек. Основной инструмент раскладки в проекте — Flexbox; CSS Grid ещё не проходили. Уровень автора — пятое занятие курса.
Задача: найди в моём CSS места, из-за которых раскладка сломается на экране шириной 375 пикселей.
Ограничения: не предлагай CSS Grid, медиазапросы, float, position: absolute и библиотеки; не переписывай мой код целиком; не предлагай менять разметку; пиши по-русски.
Формат ответа: нумерованный список, не больше пяти пунктов. В каждом: строка моего кода → что сломается на узком экране → чем заменить, одной строкой.
Критерии проверки: каждый пункт относится к строке, которая есть в моём коде; замена — валидный CSS без Grid и медиазапросов; указано, что именно увидит пользователь при поломке.

Глоссарий занятия 5

Нормальный поток
Правило браузера по умолчанию: элементы идут сверху вниз в том порядке, в каком написаны в разметке.
Блочный элемент
Начинается с новой строки и занимает всю доступную ширину: div, p, h1, li, section.
Строчный элемент
Идёт в строке по ширине содержимого: span, a, b, img.
display
Свойство, задающее способ размещения элемента: block, inline, flex.
Блочная модель
Устройство элемента из четырёх слоёв: содержимое, padding, border, margin.
padding
Внутренний отступ: от содержимого до рамки.
border
Рамка элемента.
margin
Внешний отступ: расстояние до соседних элементов. В ширину элемента не входит.
box-sizing: border-box
Режим, в котором width — это итоговая ширина, включая padding и border. Ставится первой строкой стилей всегда.
Flexbox
Механизм раскладки, расставляющий элементы вдоль одной линии. Основной инструмент раскладки на курсе.
Флекс-контейнер
Элемент с display: flex. Правила пишутся ему, слушаются его прямыми детьми.
Флекс-элемент
Прямой ребёнок флекс-контейнера.
Основная ось
Линия, вдоль которой выстроились элементы. По умолчанию слева направо.
Поперечная ось
Перпендикулярная основной. По умолчанию сверху вниз.
justify-content
Распределение элементов вдоль основной оси: flex-start, center, flex-end, space-between.
align-items
Выравнивание по поперечной оси: stretch, center, flex-start, flex-end.
flex-direction
Направление основной оси: row (по умолчанию) или column.
gap
Промежуток между элементами внутри контейнера. По краям ничего не добавляет и работает при переносе строк.
flex-wrap: wrap
Разрешение переносить элементы на новую строку, когда они не помещаются.
flex: 1 1 220px
Сокращённая запись: базовый размер элемента с правом растянуться и сжаться.
vh
Единица высоты окна: 100vh — вся высота видимой области.
min-height
Минимальная высота. В отличие от height, позволяет блоку вырасти, если содержимого больше.
float
Старый способ раскладки. На курсе для раскладки не используется.
