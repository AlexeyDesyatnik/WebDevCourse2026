Проверка формы

0 / 13

►► ЗАКАЗ

Заказ буфета «Северный пирог». Форма принимает мусор. Научи её проверять.

  • Перехвати отправку: страница не должна перезагружаться
  • Проверь три поля: имя, класс, количество
  • Сообщение появляется рядом со своим полем и объясняет, что исправить
  • Поле из одних пробелов — незаполненное
  • У неверного поля выставь aria-invalid="true", у первого из них — фокус
  • Показывай все ошибки сразу, а не по одной
  • При успехе — сообщение об успехе

Обработчик вешай на форму и слушай submit, а не click на кнопке.

Пиши здесь. Превью обновляется само. Разметку не меняй — дописывай скрипт.

Что видит браузер

►► ЭТАЛОН

Почему так: обработчик на submit ловит и кнопку, и Enter. preventDefault оставляет человека на странице. Функции возвращают текст ошибки — его сразу можно показать. Цикл проходит все поля, потом фокус. aria-invalid ставится и снимается вместе с сообщением.






  
Глоссарий

  

    
Валидация
Проверка введённых данных до того, как их принять.

    
Событие submit
Попытка отправить форму при любом способе отправки, включая Enter из поля.

    
preventDefault
Отмена перезагрузки страницы при отправке.

    
.trim()
Обрезка пробелов. Строка из пробелов — пустое поле.

    
aria-invalid
Сообщает программе чтения, что поле заполнено неверно.

  




Карточка педагога
  
    
    
  • Навык: submit + preventDefault, функции проверки (текст или «»), aria-invalid, все ошибки сразу, фокус в первое неверное.
    • 
    
  • Норматив: 16–20 мин. Scaffolding — инструкция. Разметку формы ученик не меняет.
    • 
    
  • Типичные ошибки: обработчик на кнопке; нет preventDefault; нет trim; одна ошибка вместо всех; alert и стили из скрипта.
    • 
    
  • Готово, когда: 13/13 и вслух: зачем обработчик на форме. Enter из поля имени не перезагружает страницу.
    • 
    
  • Усложнение: счётчик символов; седьмое поле со своим правилом.
    • 
    
  • Поддержка: режим блоков; файл с тремя пропусками в обработчике.
    • 
    
  • ИИ: промпт на рефакторинг. Руками: поведение то же; на месте preventDefault, trim, aria-invalid; не подмена на браузерную валидацию; тексты сообщений не изменены; ученик объясняет каждую строку.
    • 
    
  • Не проверять тестами: input и wasSubmitted — только при приёмке своего файла.
