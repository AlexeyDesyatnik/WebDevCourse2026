►► Понятие 3

Токены в :root

Шесть-восемь штук. Имена по роли, не по цвету: --accent, а не --green

:root {
  --ink: #111312;
  --accent: #7CC142;
  --radius: 18px;
}

►► Mobile First

Базовые стили — узкий экран

  • Базовое правило без колонок
  • min-width: 640 — две колонки
  • min-width: 1024 — три и другая раскладка страницы
.list { display: grid; gap: 12px; }

@media (min-width: 640px) {
  .list { grid-template-columns: repeat(2, 1fr); }
}

►► ИИ в работе

Сегодня — минимально

Каркас пишем руками: он маленький, а объяснять придётся каждую строку. Модели отдаём одно — проверку доступности разметки

[КОНТЕКСТ]
Я школьник, делаю учебный проект — веб-панель на чистых HTML, CSS
и JavaScript, без фреймворков. Сегодня написал каркас страницы.
Требования курса: семантические теги, один main, один h1, уровни
заголовков не перескакивают, label с for, осмысленный alt,
aria-label у кнопок без текста, видимый фокус.

Моя разметка:
<<< сюда вставить свой index.html целиком >>>

[ЗАДАЧА]
Проверь эту разметку на доступность и семантику. Укажи, что нарушено.

[ОГРАНИЧЕНИЯ]
- не переписывай разметку целиком, только укажи места;
- каждое замечание: где + что не так + как исправить, одной строкой;
- не предлагай библиотеки, фреймворки и внешние шрифты;
- не предлагай менять оформление и структуру страницы —
  только доступность и семантику;
- не больше восьми замечаний.

[ФОРМАТ ОТВЕТА]
Список замечаний. Каждое — одна строка. Без вступления и заключения.
Если нарушений нет — напиши одну строку «нарушений не найдено».

[КРИТЕРИИ ПРОВЕРКИ]
Каждое замечание я могу исправить одной правкой и объяснить,
почему так правильнее.

Проверить руками: замечание про реальную строку · Tab-обход сам · нет библиотек и внешних шрифтов · правку можешь объяснить · страница не сломалась · alt проверен глазами

Правило курса: сдаётся только то, что ты можешь объяснить

Глоссарий занятия 20

Каркас проекта
Разметка и раскладка страницы без данных и без поведения: семантические теги, сетка, токены, адаптив, заглушка. То, внутри чего дальше живёт вся логика.
Заглушка
Временные выдуманные данные прямо в коде, чтобы отрисовка работала до появления настоящих. Пишется по структуре данных, записанной при планировании.

Обязательный минимум занятия, ниже которого спринт не считается закрытым. На занятии 20 это публичная ссылка, открывающаяся с телефона.
Токен
Именованная переменная для значения, встречающегося больше одного раза: цвет, радиус, отступ. Объявляется в :root, используется через var(...), имя описывает роль, а не значение.
Mobile First
Способ писать стили, при котором базовые правила рассчитаны на узкий экран, а медиазапросы с min-width добавляют колонки на широком. Контрольная ширина курса — 320 px.
Семантическая разметка
Использование тегов по назначению: header, main, footer, section, article, button вместо универсального div. Основа доступности и требование ТЗ.
aria-labelledby
Атрибут, связывающий блок с его заголовком, чтобы программа чтения с экрана объявила блок по имени.
Видимый фокус
Обводка, показывающая, где находится курсор при переходе по клавише Tab. Задаётся через :focus-visible; убирать её без замены нельзя.
Проход по Tab
Минутная проверка базовой доступности без дополнительных программ: виден ли фокус, попадает ли он на все элементы управления, идёт ли в разумном порядке.
