Приложение 1. Обязательно для всех

Интерактивный Dashboard. Тема на выбор из шести. Работа индивидуально или парой.

  • HTML/CSS: Mobile First, Grid + Flexbox, тёмная тема на CSS-переменных, aria-атрибуты.
  • JavaScript: DOM, валидация форм, fetch минимум к одному публичному API, localStorage.
  • ИИ: SVG-логотип или набор иконок; подробный README, структурированный моделью; рефакторинг минимум двух сложных функций.
  • Инфраструктура: не меньше 10 осмысленных коммитов; фичи в ветках + Pull Request; публичная ссылка.
  • UX: микроанимации (наведение, клик, загрузка), понятный интерфейс.

Общие правила банка

Все шесть закрывают Приложение 1 программы. Тип данных и логика различаются. Разброс: 2 базовых, 2 повышенных, 2 высоких. Темы программы (трекер привычек, менеджер задач, кинопоиск, панель геймера) плюс школьный и социально значимый контекст.

Общие API без ключа (проверять перед курсом; в каждый проект класть data/fallback.json):

  • Open-Meteo — погода
  • Advice Slip — короткие советы
  • TVMaze — поиск сериалов/фильмов
  • Open Library — книги
  • CheapShark — скидки на игры
  • JSONPlaceholder — учебные сущности (часто режется школьным прокси)

Как педагогу раздать темы
