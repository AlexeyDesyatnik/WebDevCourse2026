P04. «Пиксельный штаб» — панель геймера

ПолеЗначение
Сложностьповышенный

ЛегендаШкольный киберклуб готовит вечер скидок и учёта «во что играли». Нужна панель: библиотека пройденных игр (своя) + блок актуальных скидок с открытого API, без логотипов магазинов-брендов в макете.
АудиторияУчастник киберклуба
ПроблемаСкидки смотрят в пяти вкладках, список «пройдено» ведут в заметках телефона

Отличие: агрегация чисел (часы, оценка) + внешний прайс-лист скидок, не поиск сюжета как в P03.

Пользовательские истории

  1. Я как игрок, хочу добавить игру в библиотеку (название, часы, оценка 1–10).
  2. Я как игрок, хочу видеть среднее время и число игр.
  3. Я как игрок, хочу загрузить подборку скидок с API.
  4. Я как игрок, хочу сохранить библиотеку локально.
  5. Я как игрок, хочу валидировать оценку (1–10) и часы (≥ 0).
  6. Я как игрок, хочу состояние «скидки недоступны — локальный список».
  7. Я как игрок, хочу удалить игру из библиотеки.
  8. Я как игрок, хочу тёмную «ночную» тему как на стриме.

MVP-граница

Обязательно: CRUD библиотеки, сводка чисел, fetch скидок, фолбэк, тема, Grid (сводка + две зоны), форма, a11y подписей.

Желательно: сортировка по оценке.

Если останется время: фильтр «оценка ≥ 8».

Покрытие ТЗ

  • API: 1) CheapShark https://www.cheapshark.com/api/1.0/deals?upperPrice=15 2) Open-Meteo виджет «не забудь разминку, если сидишь дома» 3) фолбэк 6 вымышленных сделок { "title": "Северная экспедиция", "price": "4.99" } без чужих обложек.
  • Не тащить товарные логотипы Steam/Epic.
  • localStorage: games[], settings.theme.

Экраны

Сводка (3 числа); форма; сетка библиотеки; лента скидок.

Схема данных

{
  "games": [{ "id": "g1", "title": "Северная экспедиция", "hours": 12, "score": 8 }],
  "settings": { "theme": "dark" }
}

Спринты

20: UI сводки и сеток. 21: fetch скидок + рендер ленты. 22: библиотека + localStorage + подсчёты. 23: QA чисел (среднее), README.

Подводные камни

hours как строка из input — Number, проверка Number.isFinite. CheapShark может отдать много полей — брать только title/price/sale. Не класть чужие URL картинок в репозиторий.

Демо

Добавить игру → среднее изменилось; показать ленту скидок; выключить сеть — фолбэк. Вопрос: «Где считается среднее и что будет при пустой библиотеке?» (не делить на 0).
