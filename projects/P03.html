ЛегендаСемейный киноклуб в подъезде: бабушки и подростки спорят, что смотреть в субботу. Нужен поиск по названию, карточка с рейтингом и сюжетом, список «посмотрим» без регистрации.

Отличие: поиск по внешней каталожной базе, избранное локально, много карточек результатов.

Пользовательские истории

  1. Я как зритель, хочу ввести название и увидеть список карточек.
  2. Я как зритель, хочу открыть подробности выбранного тайтла.
  3. Я как зритель, хочу добавить тайтл в «Посмотрим».
  4. Я как зритель, хочу убрать из списка.
  5. Я как зритель, хочу видеть сообщение, если ничего не найдено.
  6. Я как зритель, хочу видеть сообщение, если сети нет — и работать с локальным каталогом.
  7. Я как зритель, хочу, чтобы пустой запрос не уходил на сервер.
  8. Я как зритель, хочу тёмной темой смотреть вечером без «белой вспышки».
  9. Я как зритель, хочу, чтобы «Посмотрим» сохранился.

MVP-граница

Обязательно: поиск, список результатов, избранное, пустые/ошибочные состояния, фолбэк JSON, форма поиска, тема, Grid карточек, доступное поле поиска (label), Git/ИИ.

Желательно: фильтр «только сериалы».

Если останется время: отметка «уже видели».

Покрытие ТЗ

  • API: 1) TVMaze https://api.tvmaze.com/search/shows?q= 2) Open Library как запасной «книги по мотивам» 3) Advice Slip не подходит как каталог — не использовать третьим каталогом; третьим держать локальный fallback.json (8 вымышленных тайтлов). Не использовать постеры чужих фильмов с копирайтом: в эталоне — цветные плейсхолдеры и вымышленные названия, с TVMaze — только данные API без складирования чужих баннеров в репозиторий (горячая ссылка или плейсхолдер).
  • Grid: результаты; Flex: карточка (постер-плейсхолдер + текст).
  • localStorage: массив избранного { id, title, year, summary }.

Экраны

Поиск; результаты; боковая/нижняя панель «Посмотрим»; деталь в модалке (dialog или самодельная с фокусом и Escape — навык занятия 10).

Схема данных

{
  "watchlist": [{ "id": "tv-123", "title": "Вымышленный маяк", "year": "2019", "note": "" }],
  "settings": { "theme": "dark" }
}

Спринты

20: сетка, модалка-заглушка, форма. 21: fetch TVMaze + состояния загрузки/ошибки/пусто. 22: watchlist в localStorage, тема, анимация карточек. 23: без сети открыть фолбэк, README.

Подводные камни

CORS редко, но школьный прокси режет TVMaze — фолбэк обязателен с занятия 21. Длинный HTML в summary — textContent, не innerHTML. Пустой q — 400 от API.

Демо

Найти запрос → открыть карточку → добавить в список → F5. Затем отключить сеть в DevTools и показать фолбэк. Вопрос: «Почему нельзя вставлять описание через innerHTML?»
