# Банк из 6 проектных решений (занятия 20–24)

Все шесть закрывают Приложение 1 программы. Тип данных и логика **различаются**. Разброс: 2 базовых, 2 повышенных, 2 высоких. Темы программы (трекер привычек, менеджер задач, кинопоиск, панель геймера) плюс школьный и социально значимый контекст.

Общие API без ключа (проверять перед курсом; в каждый проект класть `data/fallback.json`):

- Open-Meteo — погода
- Advice Slip — короткие советы
- TVMaze — поиск сериалов/фильмов
- Open Library — книги
- CheapShark — скидки на игры
- JSONPlaceholder — учебные сущности (часто режется школьным прокси)

# P01. «Ритм 21» — трекер привычек

| Поле | Значение |
|---|---|
| Сложность | **базовый** |
| На кого | 13–15 лет, уверенно прошли занятия 8–12 по инструкции |
| Легенда | Школьный психолог Марина просит панель для кружка «Здоровые привычки»: подростки отмечают сон, воду и прогулку 21 день. Бумажные таблицы теряются, в чате невозможно увидеть серию дней. Нужен личный трекер без регистрации. |
| Аудитория | Подросток, который ведёт 3–7 привычек |
| Проблема | Срывы незаметны, нет «серии дней», мотивация гаснет к концу недели |

## Пользовательские истории

1. Я как ученик, хочу добавить привычку с названием и цветом, чтобы видеть её на доске.
2. Я как ученик, хочу отметить привычку за сегодня, чтобы серия дней росла.
3. Я как ученик, хочу снять отметку, если отметил по ошибке.
4. Я как ученик, хочу видеть серию (streak) и календарь 7 дней, чтобы не бросить на третий день.
5. Я как ученик, хочу получить совет дня с API, чтобы экран не был пустой таблицей.
6. Я как ученик, хочу переключить тёмную тему вечером.
7. Я как ученик, хочу, чтобы данные не пропали после закрытия вкладки.
8. Я как ученик, хочу форму добавления с проверкой пустого имени.

## MVP-граница

**Обязательно:** список привычек, отметка сегодня, streak, форма добавления, fetch совета или погоды, localStorage, Mobile First, Grid+Flex, тема, aria у чекбоксов и кнопок, 10+ коммитов, ветка+PR, README, SVG-логотип.

**Желательно:** календарь 21 дня, архив привычки.

**Если останется время:** экспорт JSON, график из CSS.

## Покрытие ТЗ

- Grid: сетка карточек привычек; Flex: шапка и ряд кнопок карточки.
- Тема: `--bg`, `--text`, `--accent` в `:root` и `[data-theme="dark"]`.
- Форма: название привычки, `preventDefault`, trim, ошибка в `aria-live`.
- API: 1) Advice Slip 2) Open-Meteo (как «погода для прогулки») 3) Open Library (`subject:self-help`, осторожно с объёмом) + `data/fallback.json` `{ "advice": "…" }`.
- DOM: рендер карточек из массива, обработчики отметок.
- localStorage: см. схему.
- ИИ: логотип «21», README, рефакторинг `toggleHabit` и `countStreak`.

## Экраны

1. Дашборд — карточки привычек, совет/погода, переключатель темы.
2. Форма «Новая привычка» (на той же странице).
3. Состояние пустого списка — приглашение добавить первую.

## Схема данных

```json
{
  "habits": [
    { "id": "h1", "title": "Вода 6 стаканов", "color": "#0f766e", "createdAt": "2026-03-01", "checks": ["2026-03-01", "2026-03-02"] }
  ],
  "settings": { "theme": "light" }
}
```

## Спринты

| Занятие | Готово |
|---|---|
| 20 | Каркас, карточки-заглушки, тема CSS, репозиторий |
| 21 | Рендер из массива, форма, fetch совета + фолбэк |
| 22 | localStorage, streak, микроанимации чекбокса = MVP |
| 23 | Тест на телефоне, README, деплой |

## ИИ-промпты

1. SVG: «Нарисуй простой логотип трекера привычек: круг из 21 деления и галочка. Только SVG, без градиентов брендов, viewBox 64 64, без фиксированной width/height в px». Проверить: открывается в браузере, нет лишних xmlns:xlink, масштабируется.
2. README: контекст проекта + стек + что сделано ИИ + ссылка. Проверить: ссылка живая, нет выдуманных библиотек.
3. Рефакторинг `countStreak` и `toggleHabit`. Проверить: серии считаются по календарным дням, не по длине массива.

Отличие от P01: не отметки по датам, а **CRUD + статусы** (очередь / в работе / готово) и фильтр.

## Пользовательские истории

2. Я как ученик, хочу перевести задачу в «В работе» и «Готово».
3. Я как ученик, хочу удалить задачу, подтвердив действие.
4. Я как ученик, хочу фильтровать «только на этой неделе».
5. Я как ученик, хочу видеть число задач в каждой колонке.
6. Я как ученик, хочу подтянуть учебный список дел из API как черновики.
7. Я как ученик, хочу, чтобы пустое название нельзя было сохранить.
8. Я как ученик, хочу тёмную тему и сохранение доски.

## MVP-граница

**Обязательно:** три колонки, создание/смена статуса/удаление, счётчики, валидация, fetch заготовок, localStorage, адаптив (на узком — колонки столбиком), тема, aria (кнопки статуса), Git/деплой/ИИ по программе.

**Желательно:** срок «просрочено» цветом.

**Если останется время:** поиск по названию.

## Покрытие ТЗ

- Grid: три колонки статусов; Flex: карточка задачи (текст + кнопки).
- API: 1) JSONPlaceholder `/todos` 2) Open-Meteo (блок «сегодня плохая погода — не откладывай прогулку с собакой» как виджет, не список задач) 3) Advice Slip как подсказка «с чего начать» + `fallback.json` массив `{ "title": "Собрать черновик презентации" }`.
- Форма: название, срок (date), `required` + JS.
- localStorage: массив задач.

## Экраны

Одна страница: виджет API + форма + три колонки. Пустые колонки с текстом «Перетаскивать не нужно — кнопки статуса».

## Схема данных

```json
{
  "tasks": [
    { "id": "t1", "title": "Черновик стенгазеты", "due": "2026-03-12", "status": "todo" }
  ],
  "settings": { "theme": "dark", "filter": "all" }
}
```

`status`: `todo` | `doing` | `done`.

## Спринты

20: сетка колонок, карточки-заглушки. 21: CRUD в памяти + fetch заготовок. 22: localStorage, фильтр, тема, анимация появления карточки. 23: QA, README.

## ИИ-промпты

1. SVG-логотип канбан-доски (три прямоугольника), без логотипов компаний.
2. README со схемой статусов.
3. Рефакторинг `moveTask` и `renderBoard`.
4. 8 тестовых задач с разными due.

## Подводные камни

Мутация массива без рендера — требовать одну функцию `renderBoard()`. Удаление без подтверждения. Просроченный `due` сравнивать строками YYYY-MM-DD, не `Date` в UTC вслепую.

## Приёмка / демо

Показать цикл: создать → в работу → готово → обновить вкладку. На узком экране колонки друг под другом. Вопрос: «Где в коде решается, в какую колонку попадёт карточка?»

**Желательно:** фильтр «только сериалы».

**Если останется время:** отметка «уже видели».

## Покрытие ТЗ

- API: 1) TVMaze `https://api.tvmaze.com/search/shows?q=` 2) Open Library как запасной «книги по мотивам» 3) Advice Slip не подходит как каталог — не использовать третьим каталогом; третьим держать **локальный** `fallback.json` (8 вымышленных тайтлов). Не использовать постеры чужих фильмов с копирайтом: в эталоне — цветные плейсхолдеры и вымышленные названия, с TVMaze — только данные API без складирования чужих баннеров в репозиторий (горячая ссылка или плейсхолдер).
- Grid: результаты; Flex: карточка (постер-плейсхолдер + текст).
- localStorage: массив избранного `{ id, title, year, summary }`.

Поиск; результаты; боковая/нижняя панель «Посмотрим»; деталь в модалке (`dialog` или самодельная с фокусом и Escape — навык занятия 10).

```json
{
  "watchlist": [{ "id": "tv-123", "title": "Вымышленный маяк", "year": "2019", "note": "" }],

```

## Спринты

20: сетка, модалка-заглушка, форма. 21: fetch TVMaze + состояния загрузки/ошибки/пусто. 22: watchlist в localStorage, тема, анимация карточек. 23: без сети открыть фолбэк, README.

## Подводные камни

CORS редко, но школьный прокси режет TVMaze — фолбэк обязателен с занятия 21. Длинный HTML в `summary` — `textContent`, не `innerHTML`. Пустой `q` — 400 от API.

**Если останется время:** фильтр «оценка ≥ 8».

- localStorage: `games[]`, `settings.theme`.

# P06. «Банк добрых дел» — волонтёрская панель

| Поле | Значение |
|---|---|
| Сложность | **высокий** |
| На кого | 16–18 лет или сильная пара; нужны часы, записи на акцию, итог влияния |
| Легенда | Волонтёрский отряд «Тёплая парта» помогает младшим с учёбой и собирает книги. Координатору нужно видеть акции, запись участников, закрытые часы и витрину книг, которые отряд рекомендует младшим (открытый книжный API). Заказчик — педагог-организатор, отчёт в конце четверти. |
| Аудитория | Волонтёры 13–18 и координатор |
| Проблема | Часы считают в таблице Excel, запись — в чате, книги — «потом пришлю ссылку» |

Отличие: **запись на событие + суммирование часов + внешний книжный поиск**. Социально значимый контекст.

## Пользовательские истории

1. Я как координатор, хочу создать акцию (название, дата, слоты).
2. Я как волонтёр, хочу записаться на акцию своим именем и классом.
3. Я как координатор, хочу отметить часы по акции.
4. Я как волонтёр, хочу видеть сумму моих часов (фильтр по имени).
5. Я как волонтёр, хочу найти книгу в Open Library и добавить в витрину «младшим почитать».
6. Я как гость, хочу понять, сколько часов отряд закрыл всего.
7. Я как координатор, хочу не принять запись без имени.
8. Я как координатор, хочу работу без сети с локальным списком книг.
9. Я как педагог, хочу тёмную тему и сохранение.

## MVP-граница

**Обязательно:** акции, запись, сумма часов (всего и/или по имени), поиск книги + витрина, фолбэк книг, формы, тема, адаптив.

**Желательно:** лимит слотов («мест нет»).

**Если останется время:** бейдж «10 часов».

## Покрытие ТЗ

- Grid: карточки акций + витрина книг; Flex: форма записи.
- API: 1) Open Library search 2) Open-Meteo «погода на уличную акцию» 3) фолбэк 6 вымышленных книг `{ "title": "Северные истории", "author": "А. Волкова" }`.
- Не использовать обложки издательств — плейсхолдер.
- localStorage: акции, записи, книги витрины.

## Экраны

Сводка часов; список акций с формой записи; витрина книг с поиском.

## Схема данных

```json
{
  "events": [{ "id": "e1", "title": "Помощь 5 классам", "date": "2026-03-18", "hours": 2, "slots": 6 }],
  "signups": [{ "eventId": "e1", "name": "Кира П.", "className": "8Б" }],
  "books": [{ "title": "Северные истории", "author": "А. Волкова" }],
  "settings": { "theme": "light" }
}
```

Сумма часов: не путать «часы акции × число людей» и «часы одного человека» — в README выбрать одну формулу и держаться её (рекомендация: сумма `hours` акций, на которые человек записан).

## Спринты

20: каркас сводки и двух сеток. 21: Open Library + погода, состояния поиска. 22: записи, часы, localStorage, лимит слотов если успеют. 23: сверка формулы часов, README для организатора.

## Подводные камни

Двойная запись на одну акцию. Часы как строки. Open Library отдаёт большие JSON — брать `docs[0].title` и `author_name[0]`. Школьный прокси.

## Демо

Запись на акцию → сумма часов выросла; поиск книги → карточка в витрине; отчёт «всего часов отряда». Вопрос: «Как считается сумма и где это написано в README?»
