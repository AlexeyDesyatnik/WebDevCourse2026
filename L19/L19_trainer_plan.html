►► ЗАКАЗ

Перед тобой чужой проект — панель задач. Сначала разбери шесть ситуаций планирования. Потом разложи двенадцать задач по четырём спринтам так, чтобы ни одна не оказалась раньше той, от которой зависит. В конце выбери верный критерий «Готово, если» для каждого спринта. Порог: 5 ситуаций из 6, ни одной нарушенной зависимости, 3 верных критерия из 4.

  • Тема карточек — «Дедлайн-доска» (P02). Это учебный сценарий, не твой репозиторий.
  • Кнопка «Проверить» смотрит все три вкладки сразу. Переключение вкладок ответы не сбрасывает.
  • Зависимости на карточках названы специально: знать их — ещё не значит разложить верно.

►► СИТУАЦИИ

Шесть карточек. Серые деления полосы — ещё без ответа.

►► СПРИНТЫ

Двенадцать задач панели «Дедлайн-доска». Перетащи карточку в зону или кликни по карточке, затем по занятию — на тачпаде так надёжнее. При наведении видны зависимости; их не прячем. Счётчик зоны краснеет, если задач больше пяти.

Ещё не в спринте

►► КРИТЕРИИ

Для каждого спринта — один вариант «Готово, если».

►► РАЗБОР

Эталон открывается после порога или трёх подсказок. Зависимости проверяются порядком, а не копированием колонки «верный спринт»: задачу 9 можно поставить и в 21-й, и в 22-й.

Глоссарий

Декомпозиция
Разбиение большой задачи на несколько маленьких, каждая из которых делается и проверяется отдельно.
User story
Формулировка задачи глазами пользователя: кто, чего хочет и зачем.
Критерий приёмки
Проверяемое условие, по которому видно, что задача закончена.
Зависимость
Ситуация, когда одна задача не может быть сделана раньше другой.
Карточка педагога
  • Навык: декомпозиция ТЗ на 4 спринта, порядок по зависимостям, критерий «Готово, если».
  • Норматив: 15–25 мин. Редактора и превью нет — это сценарий, не подмена проекта.
  • Типичные ошибки: тема по названию; localStorage в спринте 1; «работает» вместо действия; семь задач в спринт; жёсткое копирование эталонной колонки (задача 9 только в 22).
  • Готово, когда: тесты 2–7 ≥ 5/6; тесты 8, 9, 10 зелёные; тест 11 ≥ 3/4. Не требовать 11/11: три верных критерия — порог.
  • Усложнение: свой план P03–P06 без подглядывания в банк, схема зависимостей стрелками.
  • Поддержка: готовые 12 карточек и вопрос «всё ли нужное уже выше?»; критерии по формуле «открываю — нажимаю — вижу».
  • Ловушка теста 9: спринт задачи ≥ max(спринты зависимостей). Не сверять с колонкой эталона.
  • ИИ: модель проверяет порядок и время, план не составляет. Руками: каждая названная зависимость существует; новых возможностей нет.
