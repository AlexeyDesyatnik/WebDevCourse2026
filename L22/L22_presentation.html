►► Хранилище браузера

Что умеет и чего не умеет

  • Умеет: переживать закрытие, работать без сети, отдавать мгновенно
  • Не умеет: хранить не-строки, переноситься между устройствами, всегда быть доступным
localStorage.getItem("нет")  // null

►► Так нельзя

Массив без JSON.stringify

►► Так нельзя

В хранилище попадёт "[object Object],[object Object]". Ошибки не будет — данные испортятся тихо

localStorage.setItem("items", items);

►► Понятие 1

Две точки в коде

  • Сохранение — после каждого изменения.
  • Восстановление — один раз при загрузке, до отрисовки
function update() {
  renderList();
  save();
}

►► Понятие 3

Защитное чтение

Три уровня:

  • хранилище может быть недоступно
  • строка может быть испорчена
  • данные могут быть не той формы
if (!Array.isArray(data)) return [];

►► Тёмная тема

Те же имена, другие значения

Переопределяем токены под html[data-theme="dark"]. Правила ниже не меняются вообще

html[data-theme="dark"] {
  --bg: #14171A;
  --ink: #ECEFEA;
  --accent: #8FD456;
}

►► Порядок при загрузке

Тема — до отрисовки

  • 1 применить тему
  • 2 прочитать данные
  • 3 положить в массив
  • 4 отрисовать

►► Микроанимации

Три штуки, 120–250 мс

  • Только transform и opacity
  • transition в базовом правиле, не в :hover
  • prefers-reduced-motion обязателен
.card {
  transition: transform 160ms ease;
}
.card:hover { transform: translateY(-2px); }

►► Так нельзя

transition внутри :hover

►► Так нельзя

Туда плавно, обратно рывком. Плюс all и 500 мс — на школьной машине подтормаживает

.card:hover {
  transition: all 500ms ease;
  transform: translateY(-10px);
}

Глоссарий занятия 22

Точка сохранения
Место в коде, откуда вызывается запись состояния: сразу после каждого изменения данных. Надёжнее всего — внутри одной функции вместе с перерисовкой.
Точка восстановления
Единственное место, где сохранённое читается: при загрузке страницы, после применения темы и до отрисовки.
Сериализация
Превращение объекта или массива в строку через JSON.stringify для записи в хранилище; обратное превращение — JSON.parse.
Защитное чтение
Чтение из хранилища с тремя уровнями проверки: доступность хранилища, целостность строки, форма разобранных данных. Функция чтения возвращает данные или пустой массив, но никогда не роняет страницу.
Array.isArray
Проверка, что значение является массивом. Нужна после JSON.parse: испорченная строка может разобраться в число или объект без всякой ошибки.
Версия ключа хранилища
Суффикс вида -v1 в имени ключа. Меняется, когда новая структура данных несовместима со старой; при совместимых изменениях вместо смены версии подставляют значение по умолчанию.
Значение по умолчанию
То, что подставляется вместо отсутствующего поля при чтении старых данных. Позволяет добавлять необязательные поля, не меняя версию ключа.
Первый визит
Состояние, когда пользователь открывает панель впервые и в хранилище ничего нет. Проверяется в приватном окне браузера; именно здесь чаще всего падает непроверенное чтение.
Микроанимация
Короткое изменение вида элемента в ответ на действие: наведение, нажатие, появление. Длительность 120–250 мс, анимируются только transform и opacity, transition пишется в базовом правиле.
MVP-приёмка
Сценарий из восьми действий, который посторонний человек выполняет по публичной ссылке: открыть, добавить, ошибиться, перезагрузить, переключить тему, отключить сеть, посмотреть на узком экране, посмотреть консоль.
Сокращение объёма
Реакция на недостигнутый MVP: вычеркнуть вторую часть backlog, упростить обязательные задачи, несделанное честно записать в «известные ограничения» README. Не догонять, а сокращать.
