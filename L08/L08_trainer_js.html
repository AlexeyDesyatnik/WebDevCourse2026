Заказ

Заказ буфета «Северный пирог». Научи страницу считать сумму заказа.

Как сделать кодом

  • Возьми количество из поля и преврати в число
  • Посчитай сумму в отдельной функции с return
  • От 3 штук скидка 10 ₽, от 5 — 30 ₽
  • Выведи результат шаблонной строкой в обратных кавычках
  • Только const и let, только ===. Без var, == и alert

Как сделать блоками

Слева блоки, справа поля: скидка, сумма, обработчик. Внизу — страница.

Эталон-цель

Количество 3 → 125 ₽. Количество 5 → 195 ₽. Результат на странице, не в консоли.

Подсказки

Три подсказки. На демо — своими словами.

Открой консоль и выведи туда inputCount.value вместе с typeof. Что там на самом деле — число или строка? И второй вопрос: твоя функция что делает с результатом — показывает его или отдаёт?
Порядок работы: const count = Number(inputCount.value) — преобразовать сразу. Функция calcDiscount(count) с условиями от большего к меньшему и return в каждой ветке. Функция calcTotal(price, count) считает произведение и вычитает скидку, тоже через return. В обработчике — вызвать и записать в out.textContent шаблонной строкой.
function calcDiscount(count) {
  if (count >= 5) {
    return DISCOUNT_FROM_5;
  } else if (count >= 3) {
    return DISCOUNT_FROM_3;
  }
  return 0;
}

function calcTotal(price, count) {
  const sum = price * count;
  return sum - calcDiscount(count);
}

btnCalc.addEventListener("click", function () {
  const count = Number(inputCount.value);
  const total = calcTotal(PRICE, count);
  out.textContent = `${count} шт. × ${PRICE} ₽ = ${total} ₽`;
});

Эталонное решение

Откроется, когда все проверки зелёные или открыты три подсказки.

Почему так: значение из поля — строка, даже при type="number". Number() превращает её сразу. Функция считает и отдаёт результат через return, а не печатает в консоль. Условия скидки идут от большего к меньшему, иначе пять штук никогда не получат 30 ₽. Шаблонная строка собирает текст на странице.


      

    


    

      
Глоссарий занятия

      

        
const / let

        
Современные объявления. var на курсе не используется.

        
Number()

        
Преобразование строки из поля в число.

        
return

        
То, что функция отдаёт наружу. Не путать с console.log.

        
Шаблонная строка

        
Обратные кавычки и подстановка ${…}.

        
===

        
Строгое сравнение. На курсе только оно, не ==.
