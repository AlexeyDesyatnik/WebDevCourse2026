Скрипт подключают в конце <body>

  • Браузер читает документ сверху вниз
  • Скрипт в <head> выполнится до разметки
  • Найти кнопку, которой ещё нет, нельзя
<body>
  <button id="btn">Посчитать</button>
  <script>
    const btn = document.getElementById("btn");
  </script>
</body>

►► ПОНЯТИЕ

Переменные: const по умолчанию

  • const — значение не меняется
  • let — меняется
  • var — устаревшее, на курсе не пишем
  • Имя говорит, что внутри: price, а не x
const PRICE = 45;
let count = 3;
let total = PRICE * count;

Сейчас сорок пять плюс десять даст четыреста пятьдесят один

►► ПОНЯТИЕ

Число и строка — разные вещи

  • Число складывают: 45 + 10 = 55
  • Строку склеивают: "45" + 10 = "4510"
  • Значение из поля ввода — всегда строка
  • Даже если поле type="number"
console.log(typeof input.value);
// "string", даже если введено 3

►► ЖИВОЙ КОД

Преобразуй сразу при получении

Number() превращает строку в число. Не получилось — вернёт NaN, и оно заразно: попадёт во всё вычисление

const raw = input.value;   // "3"
const count = Number(raw); // 3
const total = PRICE * count;

►► ВОПРОС

На странице «Итого: NaN ₽». Что случилось?

Обсуждаем вслух. Ответ не показываем

►► ЖИВОЙ КОД

Функция: положил данные — получил результат

  • (price, count) — параметры, вход
  • return — то, что функция отдаёт
  • Вызвать можно сколько угодно раз, с разными данными
function calcTotal(price, count) {
  const sum = price * count;
  return sum;
}
calcTotal(45, 3);   // 135

►► ТАК НЕЛЬЗЯ

В консоли всё верно, а на странице «undefined». Функция показала результат, но не отдала его

function calcTotal(price, count) {
  console.log(price * count);
}

►► ПОНЯТИЕ

Условие и строгое сравнение

  • if (count >= 5) … else if (count >= 3)
  • Проверяются сверху вниз, срабатывает первое
  • Порядок: от большего к меньшему
  • Только === и !==. == прячет ошибки
if (count >= 5) {
  return 30;
} else if (count >= 3) {
  return 10;
}

►► ТАК НЕЛЬЗЯ

Одинарное = в условии

►► ТАК НЕЛЬЗЯ

Записывает 3 в переменную, и условие истинно всегда. Ни ошибки, ни предупреждения — программа просто считает неверно

if (count = 3) {
  total = total - 10;
}

►► ЖИВОЙ КОД

Шаблонная строка

Обратные кавычки — клавиша слева от единицы. Внутри ${…} можно писать любое выражение

`${count} шт. × ${price} ₽ = ${total} ₽`
// 3 шт. × 45 ₽ = 135 ₽

►► ЗАЧЕМ

Консоль — не место для ошибок, а инструмент

  • Не гадай, что в переменной — выведи и посмотри
  • Ошибка называет тип, описание и номер строки
  • Cannot read properties of null — скрипт выше разметки или опечатка в id
  • alert для отладки не используем: он блокирует страницу
console.log("count:", count, typeof count);

►► ИИ НА ЗАНЯТИИ

Промпт: объясни мой код построчно

Ты объясняешь готовый код построчно ученику, который первый день пишет на JavaScript.
Контекст: страница школьного буфета, счётчик суммы заказа. Только чистый JavaScript, без библиотек и фреймворков. Ученик знает: переменные `const` и `let`, типы число и строка, функции, условие `if`.
Задача: объясни мой код построчно — что делает каждая строка и что сломается, если её убрать.
Ограничения: не переписывай мой код и не предлагай улучшений; не используй слова, которых нет в моём коде, без объяснения; не упоминай `var`, стрелочные функции и методы массивов — мы их ещё не проходили; пиши по-русски, короткими предложениями.
Формат ответа: таблица из трёх колонок — строка кода, что делает, что сломается без неё.
Критерии проверки: каждая строка моего кода разобрана; в объяснении нет терминов без пояснения; ничего не добавлено сверх того, что есть в коде.

Глоссарий занятия 8

JavaScript
Язык программирования браузера. Третий слой страницы: поведение.
Скрипт
Код на JavaScript, подключённый к странице. Ставится в конце <body>.
Переменная
Именованное хранилище для значения.
const
Объявление переменной, значение которой не будет меняться. Берётся по умолчанию.
let
Объявление переменной, значение которой будет меняться.
var
Устаревшее объявление. На курсе не используется; встречается в старом коде и в ответах ИИ.
Тип данных
Какого сорта значение: число, строка, логическое.
Число
Значение для счёта. Дробные пишутся через точку.
Строка
Текст в кавычках. Значение из поля ввода — всегда строка.
Логическое значение
true или false. Результат любого сравнения.
typeof
Оператор, возвращающий название типа значения.
Number()
Преобразование строки в число.
NaN
«Не число». Результат неудачного преобразования. Распространяется на всё вычисление.
null
«Здесь намеренно пусто».
undefined
«Сюда ничего не положили». Возвращается функцией без return.
Оператор
Знак действия: +, -, *, /, %, >, ===, &&.
Склейка
Поведение + со строками: "45" + 10 даёт "4510".
Шаблонная строка
Строка в обратных кавычках со вставкой значений через ${…}.
Функция
Кусок кода с именем, который принимает данные и возвращает результат.
Параметр
Данные, которые функция принимает на вход. Живут только внутри неё.
return
То, что функция отдаёт наружу. Завершает выполнение функции.
Стрелочная функция
Краткая запись: const calc = (a, b) => a * b.
Условие (if)
Развилка: если условие истинно — одно, иначе — другое.
===
Строгое сравнение: сравнивает значение и тип. На курсе используется только оно.
==
Нестрогое сравнение: приводит типы друг к другу. Прячет ошибки, на курсе не используется.
console.log
Вывод значения в консоль. Показать себе, а не отдать программе.
Консоль
Вкладка DevTools с сообщениями браузера. Первое место, куда смотрят при поломке.
addEventListener
Назначение обработчика события. Единственный способ, принятый на курсе. Подробно — на занятии 10.
