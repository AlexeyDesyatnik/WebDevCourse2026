►► ПОНЯТИЕ

DOM: дерево, а не текст

  • Браузер разбирает разметку и строит дерево объектов
  • Каждый тег — узел, у узлов есть родители и дети
  • Дерево можно менять из JavaScript
  • Изменения живут до перезагрузки
document.querySelector("#menu")

►► ЖИВОЙ КОД

Найти элемент

  • querySelector — первый подходящий или null
  • querySelectorAll — все
  • Селекторы те же, что в CSS
  • Ищи один раз, наверху, и сохраняй в переменную
const menu = document.querySelector("#menu");
const cards = document.querySelectorAll(".card");

►► ПОНЯТИЕ

Изменить содержимое

  • textContent — текст, разметка не разбирается
  • innerHTML — разметка, браузер создаёт узлы
  • classList — переключение классов
box.textContent = "<b>Хит</b>";  // видно скобки
box.innerHTML   = "<b>Хит</b>";  // жирный текст

►► ТАК НЕЛЬЗЯ

Пользовательский текст в innerHTML

innerHTML разбирает строку как разметку. Если туда попадёт то, что ввёл человек, браузер выполнит вставленное

►► ТАК НЕЛЬЗЯ

out.innerHTML = "Привет, " + name;
out.textContent = "Привет, " + name;

Правило: свои данные — innerHTML, пользовательские — textContent

Сейчас страница нарисуется сама

►► ЖИВОЙ КОД

Рисуем из данных: три шага

  • map — каждый объект в строку разметки
  • join("") — склеить
  • innerHTML — положить в контейнер
  • Контейнер в разметке пустой
menu.innerHTML = pies
  .map((pie) => `<li class="card" data-id="${pie.id}">${pie.name}</li>`)
  .join("");

►► ПОНЯТИЕ

События и обработчики

  • Событие — что произошло, обработчик — что делать
  • addEventListener(событие, функция)
  • Функция передаётся без скобок
  • Обработчиков может быть несколько
btn.addEventListener("click", myHandler);   // верно
btn.addEventListener("click", myHandler()); // вызов

►► ТАК НЕЛЬЗЯ

onclick в разметке

Поведение перемешано с разметкой. Обработчик может быть только один. Снять его нельзя

►► ТАК НЕЛЬЗЯ

<button onclick="calc()">Посчитать</button>

►► ВОПРОС

Карточки создаёт скрипт. Как повесить на них обработчик?

Обсуждаем вслух. Задача выглядит неразрешимой — и в этом смысл вопроса

►► ЖИВОЙ КОД

Делегирование

  • Событие всплывает вверх по дереву
  • Один обработчик на контейнер, который есть всегда
  • closest поднимается от места нажатия до карточки
  • Работает после любой перерисовки
menu.addEventListener("click", (event) => {
  const card = event.target.closest(".card");
  if (card === null) return;
  const pie = PIES.find((p) => p.id === card.dataset.id);
});

►► ТАК НЕЛЬЗЯ

event.target вместо closest

Нажал по краю карточки — сработало. Нажал по названию — нет: event.target это заголовок, а у него нет data-id

►► ТАК НЕЛЬЗЯ

const card = event.target;
card.dataset.id;   // undefined

►► ЖИВОЙ КОД

Модальное окно

  • Лежит в разметке всегда, скрыто классом
  • Скрипт переключает класс через classList
  • Содержимое — через textContent
  • Закрывается кнопкой, затемнением и Escape
modal.classList.remove("hidden");
document.addEventListener("keydown", (event) => {
  if (event.key === "Escape") closeModal();
});

Промпт: объясни мой обработчик построчно

Ты объясняешь готовый код построчно ученику, который вторую неделю пишет на JavaScript.
Контекст: страница школьного буфета. Карточки рисуются из массива объектов, обработчик нажатия назначен на контейнер. Ученик знает: переменные, функции, filter, map, find, шаблонные строки, addEventListener. Не знает: классы, модули, асинхронность.
Задача: объясни мой обработчик нажатия построчно. Отдельно ответь на вопрос: что произойдёт, если убрать строку с closest, и что — если убрать проверку на null.
Ограничения: не переписывай мой код и не предлагай улучшений; не упоминай библиотеки, классы и асинхронность; каждый термин, которого нет в моём коде, объясняй сразу; пиши по-русски короткими предложениями.
Формат ответа: таблица из трёх колонок — строка кода, что делает, что сломается без неё. После таблицы — два абзаца ответов на вопросы про closest и про проверку.
Критерии проверки: разобрана каждая строка; ответы про closest и null конкретные, с описанием того, что увидит пользователь.

Глоссарий занятия 10

DOM
Дерево объектов, которое браузер строит из разметки. Каждый тег — узел.
Узел
Один элемент в дереве DOM. У узлов есть родители, дети и соседи.
document
Объект всего документа. Точка входа для любого поиска.
querySelector
Найти первый элемент по селектору CSS. Не нашёл — null.
querySelectorAll
Найти все подходящие элементы. Возвращает список, похожий на массив.
textContent
Текст внутри элемента. Разметку не разбирает. Используется для всего, что пришло от пользователя.
innerHTML
Разметка внутри элемента. Строка разбирается как HTML. Используется только для своей разметки.
classList
Управление классами элемента: add, remove, toggle, contains.
dataset
Доступ к атрибутам data-*. Атрибут data-id читается как dataset.id.
Отрисовка из данных
Построение разметки из массива: map → join → innerHTML. Одно присваивание, не в цикле.
Событие
То, что произошло на странице: нажатие, ввод, отправка формы, нажатие клавиши.
Обработчик
Функция, которая выполняется, когда событие произошло.
addEventListener
Назначение обработчика. Функция передаётся без скобок.
Объект события
То, что обработчик получает на вход: сведения о произошедшем.
event.target
Элемент, по которому реально произошло событие. Может быть вложенным элементом, а не тем, на котором висит обработчик.
event.key
Название нажатой клавиши: "Enter", "Escape".
Всплытие
Событие происходит на элементе и поднимается вверх по дереву к родителям.
Делегирование
Один обработчик на контейнер вместо обработчика на каждом дочернем элементе. Работает с элементами, созданными позже.
closest
Подняться вверх от элемента и найти ближайшего подходящего предка.
Модальное окно
Блок поверх страницы. Лежит в разметке всегда, скрыт классом; скрипт класс переключает.
