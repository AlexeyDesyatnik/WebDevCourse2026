Заказ

Заказ буфета «Северный пирог». Нарисуй меню из данных и научи его отвечать на нажатия.

Как сделать кодом

  • renderMenu(pies) рисует карточки в #menu из массива
  • У каждой карточки класс card и атрибут data-id
  • Пустой массив — сообщение «Ничего не найдено», а не пустота
  • Кнопки фильтра переключают список
  • Нажатие по карточке — включая заголовок внутри — открывает окно с составом
  • Окно закрывается кнопкой и клавишей Escape

Обработчики вешай на контейнеры: карточек в момент запуска ещё нет.

Как сделать блоками

Слева блоки, справа поля отрисовки, окна и обработчиков. Внизу — страница.

Эталон-цель

Четыре карточки из данных. Фильтр «сладкое» оставляет две. Нажатие по названию открывает окно. Escape закрывает.

Результат

Самопроверка

Проверки нажимают кнопки и карточки в превью программно. Между нажатием и проверкой задержки нет.

Подсказки

Три подсказки. На демо — своими словами.

Держи в голове схему: найти → назначить обработчик → изменить. Для каждого куска спроси: что я ищу, на что вешаю обработчик, что меняю? И отдельный вопрос: существуют ли карточки в тот момент, когда выполняется твой скрипт?
Отрисовка: menu.innerHTML = pies.map(...).join(""), в шаблоне обязательно data-id="${pie.id}", в начале функции — проверка на пустой массив. Обработчики вешаются на контейнеры #filters и #menu, внутри — event.target.closest(...) и проверка на null. Окно: classList.remove("hidden") и classList.add("hidden"), содержимое через textContent.
function renderMenu(pies) {
  if (pies.length === 0) {
    menu.innerHTML = "<li>Ничего не найдено</li>";
    return;
  }
  menu.innerHTML = pies
    .map((pie) => `<li class="card" data-id="${pie.id}"><h3>${pie.name}</h3></li>`)
    .join("");
}

menu.addEventListener("click", (event) => {
  const card = event.target.closest(".card");
  if (card === null) return;
  const pie = PIES.find((p) => p.id === card.dataset.id);
  openModal(pie);
});

Эталонное решение

Откроется, когда все проверки зелёные или открыты три подсказки.

Почему так: карточки появляются после запуска скрипта, поэтому обработчик висит на контейнере, а не на каждой карточке. closest(".card") поднимается от заголовка к карточке. data-id связывает разметку с объектом в массиве. Класс hidden прячет готовое окно — его не создают заново. Escape слушают на document.


      

    


    

      
Глоссарий занятия

      

        
querySelector

        
Найти первый элемент. Не нашёл — null.

        
innerHTML

        
Разметка внутри элемента. Одно присваивание после map + join, не в цикле.

        
addEventListener

        
Назначить обработчик. Функцию передают без скобок. Не onclick=.

        
closest

        
Подняться к ближайшему предку. Нужен, когда нажали по заголовку внутри карточки.

        
Делегирование

        
Один обработчик на контейнер. Переживает перерисовку списка.
